What is FastAPI?

FastAPI is a Python library that helps you build APIs: programs that other programs (websites, mobile apps, AI tools) can talk to over the internet.

🥜 In a nutshell: You write normal Python functions. FastAPI turns them into web URLs that anyone can call, and it checks the data, writes docs, and sends back JSON for you.

The restaurant analogy 🍕

Think of a restaurant. You (the client) don't walk into the kitchen. You tell the waiter what you want. The waiter takes your order to the kitchen and brings back food. FastAPI is the waiter.

How FastAPI is built (the layer cake 🎂)

FastAPI doesn't do everything alone. It stands on the shoulders of other great libraries.

🥜 In a nutshell: Uvicorn listens to the internet → Starlette handles web stuff → Pydantic checks data → FastAPI glues it together with your functions.
⚡ FastAPI your routes, Depends, auto docs
🧪 Pydantic validation & types
⭐ Starlette routing, requests, websockets
🦄 Uvicorn ASGI server, talks HTTP
🐍 Python 3.9+ type hints + async/await

ASGI vs WSGI in one breath

WSGI (old, Flask/Django classic)
One request per worker at a time. Like a cashier who waits for your card to finish before helping anyone else.
ASGI (new, FastAPI)
A worker can juggle many requests while they wait. Also supports WebSockets. Like a cashier who helps the next person while your card processes.

    HTTP methods = verbs (CRUD) 📚

    The method says what you want to do. The URL says to what. Imagine a library of books.

    🥜 In a nutshell: GET = read, POST = create, PUT = replace, PATCH = edit a bit, DELETE = remove.
    GET

    Read

    "Show me book 7." Never changes data.

    POST

    Create

    "Add this new book." Sends a body.

    PUT

    Replace

    "Replace book 7 with this whole new version."

    PATCH

    Update part

    "Only change book 7's title."

    DELETE

    Remove

    "Throw away book 7."

    main.py
    from fastapi import FastAPI

app = FastAPI()
books = {1: "Harry Potter"}

@app.get("/books/{book_id}")          # READ
def read_book(book_id: int):
    return {"id": book_id, "title": books.get(book_id)}

@app.post("/books")                   # CREATE
def create_book(title: str):
    new_id = max(books) + 1
    books[new_id] = title
    return {"id": new_id, "title": title}

@app.put("/books/{book_id}")          # REPLACE
def replace_book(book_id: int, title: str):
    books[book_id] = title
    return {"id": book_id, "title": title}

@app.delete("/books/{book_id}")       # DELETE
def delete_book(book_id: int):
    books.pop(book_id, None)
    return {"deleted": book_id}

    Path parameters 🛣️

    A path parameter is a variable inside the URL, written in curly braces.

    🥜 In a nutshell: /users/{user_id} + user_id: int → visiting /users/42 gives you the number 42 (not the text "42"). Visiting /users/abc gives an automatic error.
    main.py
    from enum import Enum
from fastapi import FastAPI

app = FastAPI()

# 1. Basic: the type hint converts + validates
@app.get("/users/{user_id}")
def get_user(user_id: int):
    return {"user_id": user_id}

# 2. ORDER MATTERS: put fixed paths BEFORE variable ones
@app.get("/me")                       # fine, different path
def who_am_i():
    return {"user": "current user"}

@app.get("/files/me")                 # declared first, so it wins
def my_files():
    return {"owner": "me"}

@app.get("/files/{owner}")            # otherwise "me" would land here
def files_of(owner: str):
    return {"owner": owner}

# 3. Allowed values only: use an Enum (shows as a dropdown in /docs)
class Model(str, Enum):
    alexnet = "alexnet"
    resnet = "resnet"

@app.get("/models/{name}")
def get_model(name: Model):
    return {"model": name, "is_resnet": name is Model.resnet}

# 4. A path that contains slashes
@app.get("/download/{file_path:path}")
def download(file_path: str):
    return {"file": file_path}        # /download/docs/a/b.txt -> "docs/a/b.txt"
    ⚠️ Order matters. FastAPI checks routes top to bottom and picks the first match. Always declare /files/me before /files/{owner}.

    Query parameters ❓

    Query parameters come after the ? in a URL, joined with &. Used for filters, search, and pages.

    🥜 In a nutshell: Any function argument that is not in the path is a query parameter. Give it a default to make it optional.
    main.py
    @app.get("/users/{user_id}/items")
def read_items(user_id: int, q: str | None = None, limit: int = 10):
    #           ^ path param   ^ optional query     ^ query with default
    return {"user_id": user_id, "q": q, "limit": limit}

@app.get("/search")
def search(term: str, in_stock: bool = False):   # term has no default = REQUIRED
    return {"term": term, "in_stock": in_stock}
    # in_stock accepts: true/false, 1/0, yes/no, on/off

    Request body & Pydantic models 📦

    When a client sends lots of data (like a sign-up form), it goes in the body as JSON. You describe its shape with a Pydantic model, a class with typed fields.

    🥜 In a nutshell: A Pydantic model is a form with rules. FastAPI reads the JSON, fills the form, checks every rule, and gives you a clean Python object. If something's wrong, the client gets a 422 error listing exactly what.
    main.py
    from fastapi import FastAPI
from pydantic import BaseModel, EmailStr, Field

app = FastAPI()

class User(BaseModel):
    name: str = Field(min_length=2)       # text, at least 2 characters
    age: int = Field(gt=0)                # whole number, greater than 0
    email: EmailStr                       # must look like an email
    is_active: bool = True                # optional, default True

@app.post("/users")
def create_user(user: User):              # a model type = read from the BODY
    print(user.name, user.age)            # real attributes, with autocomplete!
    return {"saved": user.model_dump()}   # model_dump() -> plain dict

    Simple type (int, str, bool…) not in path❓ Query string

    Extra validation rules 📏

    Want "between 1 and 100" or "max 50 characters"? Add rules with Query(), Path(), Body() and Field(), using Annotated.

    🥜 In a nutshell: Annotated[type, Rule(...)] = "this type, plus these rules". Rules show up in the docs too.
    main.py
    from typing import Annotated
from fastapi import FastAPI, Path, Query, Body
from pydantic import BaseModel, Field

app = FastAPI()

@app.get("/items/{item_id}")
def read_item(
    item_id: Annotated[int, Path(ge=1, le=1000, title="The item ID")],
    q: Annotated[str | None, Query(min_length=3, max_length=50)] = None,
    page: Annotated[int, Query(ge=1)] = 1,
    tags: Annotated[list[str], Query()] = [],     # ?tags=a&tags=b -> ["a", "b"]
):
    return {"item_id": item_id, "q": q, "page": page, "tags": tags}

class Product(BaseModel):
    name: str = Field(min_length=1, max_length=100, examples=["Laptop"])
    price: float = Field(gt=0, description="Price in USD")
    code: str = Field(pattern=r"^[A-Z]{3}-\d{3}$")   # like "ABC-123"
    tags: list[str] = []

@app.post("/products")
def add_product(product: Product, importance: Annotated[int, Body(ge=1, le=5)]):
    return {"product": product, "importance": importance}
    RuleMeansWorks on
    gt / gegreater than / greater or equalnumbers
    lt / leless than / less or equalnumbers
    min_length / max_lengthsize limitsstrings, lists
    patternmust match a regexstrings
    aliasdifferent name in the URL/JSON (e.g. item-query)all
    deprecated=Truemarks it as old in docsall

    Custom validators (your own rules)

    models.py
    from pydantic import BaseModel, field_validator, model_validator

class SignUp(BaseModel):
    username: str
    password: str
    confirm: str

    @field_validator("username")
    @classmethod
    def no_spaces(cls, v: str) -> str:
        if " " in v:
            raise ValueError("username cannot contain spaces")
        return v.lower()                  # you can also clean the value

    @model_validator(mode="after")
    def passwords_match(self):
        if self.password != self.confirm:
            raise ValueError("passwords do not match")
        return self

    Response models: control what goes out 🚪

    Input and output are often different. You take a password in, but you must never send it back.

    🥜 In a nutshell: response_model (or a return type hint) is a filter on the way out. Fields not in the model are removed.
    Your function returns 
    {"username": "asha",
 "email": "a@x.com",
 "password": "s3cret!"}
    Client receives (filtered by UserOut) 🛡️ 
    {"username": "asha",
 "email": "a@x.com"}
    main.py
    from fastapi import FastAPI
from pydantic import BaseModel, EmailStr

app = FastAPI()

class UserIn(BaseModel):          # what the client SENDS
    username: str
    email: EmailStr
    password: str

class UserOut(BaseModel):         # what the client GETS
    username: str
    email: EmailStr

@app.post("/users", response_model=UserOut, status_code=201)
def create_user(user: UserIn):
    # save to DB here...
    return user                   # password is stripped automatically!

# Modern style: the return type hint does the same job
@app.get("/users/{username}")
def get_user(username: str) -> UserOut:
    return UserOut(username=username, email=f"{username}@example.com")

# Useful options
@app.get("/items/{id}", response_model=UserOut, response_model_exclude_unset=True)
def item(id: int):
    ...                           # only send fields that were actually set
    💡 A common pattern: UserBase (shared fields) → UserCreate(UserBase) adds password → UserPublic(UserBase) adds id. Inheritance keeps it short.

    Status codes & error handling 🚨

    Every response has a number. 2xx = good, 4xx = the client made a mistake, 5xx = the server broke.

    🥜 In a nutshell: Use raise HTTPException(status_code=404, detail="Not found") to stop and send an error. FastAPI already sends 422 for bad input on its own.
    200
    OK

    Everything worked (default)

    201
    Created

    New thing was made (POST)

    204
    No Content

    Done, nothing to send back (DELETE)

    400
    Bad Request

    Request makes no sense

    401
    Unauthorized

    Who are you? Log in first

    403
    Forbidden

    I know you, but you're not allowed

    404
    Not Found

    That thing doesn't exist

    422
    Unprocessable

    Data failed validation (automatic)

    500
    Server Error

    Your code crashed

    main.py
    from fastapi import FastAPI, HTTPException, Request, status
from fastapi.responses import JSONResponse

app = FastAPI()
items = {"apple": 1.5}

@app.get("/items/{name}")
def get_item(name: str):
    if name not in items:
        raise HTTPException(
            status_code=status.HTTP_404_NOT_FOUND,     # same as 404, but readable
            detail=f"Item '{name}' not found",
            headers={"X-Error": "missing-item"},       # optional
        )
    return {"name": name, "price": items[name]}

@app.post("/items", status_code=status.HTTP_201_CREATED)   # change the success code
def create_item(name: str, price: float):
    items[name] = price
    return {"name": name}

# Your own exception + a global handler for it
class OutOfStock(Exception):
    def __init__(self, name: str):
        self.name = name

@app.exception_handler(OutOfStock)
async def out_of_stock_handler(request: Request, exc: OutOfStock):
    return JSONResponse(status_code=409, content={"error": f"{exc.name} is out of stock"})

@app.get("/buy/{name}")
def buy(name: str):
    raise OutOfStock(name)                              # -> 409 + friendly JSON
    GET /items/banana → 404
    {"detail": "Item 'banana' not found"}

    Headers, cookies, forms & file uploads 📎

    Data doesn't only come in JSON. FastAPI has a helper for each place it can hide.

    🥜 In a nutshell: Wrap the type with Header(), Cookie(), Form() or use UploadFile. Same type checking as everything else.
    main.py
    from typing import Annotated
from fastapi import FastAPI, Header, Cookie, Form, File, UploadFile, Response

app = FastAPI()

# HEADERS: user_agent reads the "User-Agent" header (_ becomes -)
@app.get("/whoami")
def whoami(user_agent: Annotated[str | None, Header()] = None,
           x_token: Annotated[str | None, Header()] = None):
    return {"browser": user_agent, "token": x_token}

# COOKIES: read one...
@app.get("/cart")
def cart(session_id: Annotated[str | None, Cookie()] = None):
    return {"session": session_id}

# ...and set one
@app.post("/login-cookie")
def set_cookie(response: Response):
    response.set_cookie(key="session_id", value="abc123", httponly=True)
    return {"ok": True}

# HTML FORMS (needs python-multipart, included in fastapi[standard])
@app.post("/login")
def login(username: Annotated[str, Form()], password: Annotated[str, Form()]):
    return {"username": username}

# FILE UPLOADS
@app.post("/upload")
async def upload(file: UploadFile):
    data = await file.read()
    return {"filename": file.filename, "type": file.content_type, "size": len(data)}

@app.post("/upload-many")
async def upload_many(files: list[UploadFile], note: Annotated[str, Form()] = ""):
    return {"names": [f.filename for f in files], "note": note}
    💡 UploadFile stores big files on disk instead of memory, and gives you .filename, .content_type, await .read(), await .write(), await .seek().

    async / await: serving many at once 🔄

    Most web work is waiting: for a database, another API, a file. async lets Python serve other requests during that waiting.

    🥜 In a nutshell: A sync waiter stands at the kitchen until your food is ready. An async waiter takes everyone's orders, and brings each dish as it's ready. Same waiter, much more served.

    🐢 Sync (one after another) total: ?

    Request 1
    Request 2
    Request 3
    0s2s4s6s

    ⚡ Async (waits overlap) total: ?

    Request 1
    Request 2
    Request 3
    0s2s4s6s
    main.py
    import asyncio
import time
import httpx
from fastapi import FastAPI

app = FastAPI()

@app.get("/async-wait")
async def good():
    await asyncio.sleep(2)              # non-blocking: others run meanwhile
    return {"done": True}

@app.get("/call-other-api")
async def call_other():
    async with httpx.AsyncClient() as client:
        r = await client.get("https://api.github.com")
    return {"status": r.status_code}

@app.get("/sync-wait")
def also_fine():
    time.sleep(2)                       # blocking, but FastAPI runs plain `def`
    return {"done": True}               # in a thread pool, so it's still OK

@app.get("/BAD")
async def bad():
    time.sleep(2)                       # ❌ blocking call inside async def
    return {"oops": "froze the whole server for 2s"}
    SituationUse
    You call libraries with await (httpx, asyncpg, motor, aiofiles)async def
    You use normal blocking libraries (requests, most DB drivers, pandas)def (FastAPI runs it in a thread)
    Not sure?def is the safe choice
    Heavy CPU math (ML training, image processing)Neither helps; use background workers / processes

    Dependency Injection with Depends 🧩

    Many endpoints need the same thing first: a database session, the logged-in user, pagination settings. Write it once as a function, then "ask" for it.

    🥜 In a nutshell: Depends(func) = "before running my endpoint, run func and give me its result." Dependencies can depend on other dependencies, forming a tree. FastAPI runs them in the right order.
    get_settings()reads config
    get_db()opens DB session
    get_token()reads Authorization header
    get_current_user(db, token)finds the user
    read_profile(user)your endpoint
    Press the button to see the order.
    main.py
    from typing import Annotated
from fastapi import Depends, FastAPI, HTTPException, Header

app = FastAPI()

# 1) Simple dependency: shared query parameters
def pagination(skip: int = 0, limit: int = 10):
    return {"skip": skip, "limit": limit}

@app.get("/items")
def list_items(page: Annotated[dict, Depends(pagination)]):
    return page                                   # /items?skip=20&limit=5

# 2) Dependency with cleanup: `yield`
def get_db():
    db = {"connected": True}                      # e.g. SessionLocal()
    try:
        yield db                                  # given to the endpoint
    finally:
        db["connected"] = False                   # runs AFTER the response: close it

# 3) Dependencies that use other dependencies
def get_token(authorization: Annotated[str | None, Header()] = None):
    if not authorization:
        raise HTTPException(401, "Missing token")
    return authorization.removeprefix("Bearer ")

def get_current_user(db: Annotated[dict, Depends(get_db)],
                     token: Annotated[str, Depends(get_token)]):
    return {"name": "asha", "token": token}

# Tip: make a short alias and reuse it everywhere
CurrentUser = Annotated[dict, Depends(get_current_user)]

@app.get("/profile")
def read_profile(user: CurrentUser):
    return user

# 4) Run a dependency for its side effect only (no return value needed)
def verify_key(x_key: Annotated[str, Header()]):
    if x_key != "secret":
        raise HTTPException(403, "Bad key")

@app.get("/admin", dependencies=[Depends(verify_key)])
def admin():
    return {"welcome": "admin"}

# 5) For the WHOLE app: FastAPI(dependencies=[Depends(verify_key)])
    💡 Within one request, a dependency used in several places runs only once (its result is cached). Great for DB sessions.

    Security: login with OAuth2 + JWT 🔐

    The most common pattern: log in once, receive a token, then send that token with every request. Like a wristband at a concert.

    🥜 In a nutshell: POST /token with username + password → get a signed JWT → send Authorization: Bearer <token> → a dependency checks the token and gives you the user.
    🧑 Client
    POST /token (username=asha, password=***)
    🖥️ API
    🧑 Client
    🔍 API checks password against stored hash
    🖥️ API
    🧑 Client
    200 {"access_token": "eyJhbGci...", "token_type": "bearer"}
    🖥️ API
    🧑 Client
    GET /users/me + header Authorization: Bearer eyJhbGci...
    🖥️ API
    🧑 Client
    🔏 API verifies signature + expiry, reads "sub": "asha"
    🖥️ API
    🧑 Client
    200 {"username": "asha"}
    🖥️ API
    Terminal

    auth_app.py
    from datetime import datetime, timedelta, timezone
from typing import Annotated

import jwt
from fastapi import Depends, FastAPI, HTTPException, status
from fastapi.security import OAuth2PasswordBearer, OAuth2PasswordRequestForm
from pwdlib import PasswordHash

SECRET_KEY = "change-me"          # real apps: long random value from an env variable
ALGORITHM = "HS256"
password_hash = PasswordHash.recommended()
oauth2_scheme = OAuth2PasswordBearer(tokenUrl="token")   # adds the Authorize button in /docs

# never store plain passwords, only hashes
fake_users = {"asha": {"username": "asha", "hashed_password": password_hash.hash("secret")}}

app = FastAPI()

def create_token(username: str) -> str:
    expire = datetime.now(timezone.utc) + timedelta(minutes=30)
    return jwt.encode({"sub": username, "exp": expire}, SECRET_KEY, algorithm=ALGORITHM)

@app.post("/token")
def login(form: Annotated[OAuth2PasswordRequestForm, Depends()]):
    user = fake_users.get(form.username)
    if not user or not password_hash.verify(form.password, user["hashed_password"]):
        raise HTTPException(status.HTTP_401_UNAUTHORIZED, "Wrong username or password")
    return {"access_token": create_token(user["username"]), "token_type": "bearer"}

def get_current_user(token: Annotated[str, Depends(oauth2_scheme)]):
    try:
        payload = jwt.decode(token, SECRET_KEY, algorithms=[ALGORITHM])
    except jwt.InvalidTokenError:
        raise HTTPException(status.HTTP_401_UNAUTHORIZED, "Invalid or expired token",
                            headers={"WWW-Authenticate": "Bearer"})
    user = fake_users.get(payload.get("sub"))
    if user is None:
        raise HTTPException(status.HTTP_401_UNAUTHORIZED, "User not found")
    return user

@app.get("/users/me")
def read_me(user: Annotated[dict, Depends(get_current_user)]):
    return {"username": user["username"]}
    💡 Other built-in helpers in fastapi.security: APIKeyHeader, APIKeyQuery, APIKeyCookie, HTTPBasic, HTTPBearer, and OAuth2 scopes for permissions.

    Middleware & CORS 🧅

    Middleware is code that wraps every request and response, like layers of an onion. Great for logging, timing, adding headers.

    🥜 In a nutshell: The request goes in through each layer to your endpoint, then the response comes back out through the same layers in reverse.

    main.py
    import time
from fastapi import FastAPI, Request
from fastapi.middleware.cors import CORSMiddleware

app = FastAPI()

# Custom middleware: measure how long each request takes
@app.middleware("http")
async def add_process_time(request: Request, call_next):
    start = time.perf_counter()
    response = await call_next(request)             # go deeper into the onion
    response.headers["X-Process-Time"] = f"{time.perf_counter() - start:.4f}"
    return response                                  # coming back out

# CORS: allow a website on another domain (e.g. your React app) to call this API
app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:3000", "https://myfrontend.com"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
    🌍 What is CORS? Browsers block a page on site-a.com from calling an API on site-b.com unless the API says "site-a is allowed". That permission is CORS. Without it you'll see a red "blocked by CORS policy" error in the browser console.

    Other built-in middleware: GZipMiddleware (compress responses), TrustedHostMiddleware, HTTPSRedirectMiddleware.

    Background tasks ⏳

    Some work doesn't need to make the user wait, like sending a welcome email. Reply first, do it after.

    🥜 In a nutshell: Add a BackgroundTasks parameter, call .add_task(func, args). The function runs right after the response is sent.

    Without background task

    save + send email (3s)… then reply
    User waits 3 seconds 😴

    With background task

    reply
    email sent in background
    User gets a reply instantly ⚡
    main.py
    from fastapi import BackgroundTasks, FastAPI

app = FastAPI()

def send_welcome_email(email: str, name: str):
    # slow work: SMTP, writing logs, resizing an image...
    with open("emails.log", "a") as f:
        f.write(f"Welcome {name} -> {email}\n")

@app.post("/signup")
def signup(email: str, name: str, background_tasks: BackgroundTasks):
    background_tasks.add_task(send_welcome_email, email, name)
    return {"message": "Signed up! Check your inbox soon."}
    ⚠️ For heavy or long jobs (video processing, jobs that must survive a restart), use a real task queue like Celery, RQ or ARQ.

    Databases with SQLModel 🗄️

    SQLModel (by the same author as FastAPI) is a class that is both a database table and a Pydantic model. One class, two jobs.

    🥜 In a nutshell: Define a table=True class → create an engine → give each request a session with a yield dependency → add, commit, get, select.
    Terminal
    pip install sqlmodel
    main.py
    from contextlib import asynccontextmanager
from typing import Annotated

from fastapi import Depends, FastAPI, HTTPException
from sqlmodel import Field, Session, SQLModel, create_engine, select

class Hero(SQLModel, table=True):           # a TABLE and a Pydantic model
    id: int | None = Field(default=None, primary_key=True)
    name: str = Field(index=True)
    age: int | None = None

engine = create_engine("sqlite:///heroes.db", connect_args={"check_same_thread": False})

def get_session():
    with Session(engine) as session:        # one session per request
        yield session

SessionDep = Annotated[Session, Depends(get_session)]

@asynccontextmanager
async def lifespan(app: FastAPI):
    SQLModel.metadata.create_all(engine)    # create tables at startup
    yield

app = FastAPI(lifespan=lifespan)

@app.post("/heroes")
def create_hero(hero: Hero, session: SessionDep) -> Hero:
    session.add(hero)
    session.commit()
    session.refresh(hero)                   # get the new id from the DB
    return hero

@app.get("/heroes")
def list_heroes(session: SessionDep, offset: int = 0, limit: int = 100) -> list[Hero]:
    return session.exec(select(Hero).offset(offset).limit(limit)).all()

@app.get("/heroes/{hero_id}")
def get_hero(hero_id: int, session: SessionDep) -> Hero:
    hero = session.get(Hero, hero_id)
    if not hero:
        raise HTTPException(404, "Hero not found")
    return hero

@app.delete("/heroes/{hero_id}")
def delete_hero(hero_id: int, session: SessionDep):
    hero = session.get(Hero, hero_id)
    if not hero:
        raise HTTPException(404, "Hero not found")
    session.delete(hero)
    session.commit()
    return {"ok": True}
    💡 Swap SQLite for PostgreSQL by changing one line: create_engine("postgresql://user:pass@localhost/db"). You can also use plain SQLAlchemy, or MongoDB with motor/beanie. For changing table structure over time, use Alembic migrations.

    Lifespan events & settings ⚙️

    Some things should happen once: load an ML model at startup, close connections at shutdown. And secrets should live in environment variables, not in code.

    🥜 In a nutshell: Code before yield in lifespan runs at startup, code after runs at shutdown. pydantic-settings reads env vars / .env into a typed class.
    main.py
    from contextlib import asynccontextmanager
from functools import lru_cache
from typing import Annotated

from fastapi import Depends, FastAPI
from pydantic_settings import BaseSettings, SettingsConfigDict   # pip install pydantic-settings

class Settings(BaseSettings):
    app_name: str = "My API"
    database_url: str = "sqlite:///app.db"
    secret_key: str                       # REQUIRED: must be in env or .env
    debug: bool = False
    model_config = SettingsConfigDict(env_file=".env")

@lru_cache                                # read the file only once
def get_settings() -> Settings:
    return Settings()

ml_models = {}

@asynccontextmanager
async def lifespan(app: FastAPI):
    print("🚀 starting: loading model...")
    ml_models["sentiment"] = lambda text: "positive" if "good" in text else "negative"
    yield                                 # ---- app is running here ----
    print("🛑 shutting down: cleaning up")
    ml_models.clear()

app = FastAPI(lifespan=lifespan)

@app.get("/predict")
def predict(text: str):
    return {"label": ml_models["sentiment"](text)}

@app.get("/info")
def info(settings: Annotated[Settings, Depends(get_settings)]):
    return {"app": settings.app_name, "debug": settings.debug}
    .env (never commit this file!)
    SECRET_KEY=super-long-random-string
DEBUG=true

    WebSockets: real-time chat 💬

    Normal HTTP is like sending letters: ask, get one reply, done. A WebSocket is a phone call: the line stays open and both sides can talk any time.

    🥜 In a nutshell: @app.websocket("/ws") → await ws.accept() → loop: receive_text() / send_text(). Used for chats, live dashboards, games, streaming AI replies.
    Hi server 👋
    You said: Hi server 👋
    📈 Live price update: 101.4
    Thanks!
    You said: Thanks!
    main.py
    from fastapi import FastAPI, WebSocket, WebSocketDisconnect

app = FastAPI()
clients: list[WebSocket] = []

@app.websocket("/ws/{name}")
async def chat(websocket: WebSocket, name: str):
    await websocket.accept()
    clients.append(websocket)
    try:
        while True:
            text = await websocket.receive_text()
            for c in clients:              # broadcast to everyone
                await c.send_text(f"{name}: {text}")
    except WebSocketDisconnect:
        clients.remove(websocket)

    const ws = new WebSocket("ws://127.0.0.1:8000/ws/asha");
ws.onmessage = (e) => console.log(e.data);

    Other response types, static files & templates 🎨

    JSON is the default, but you can return HTML, files, redirects, or stream data piece by piece.

    🥜 In a nutshell: Return a dict → JSON. Return a HTMLResponse, FileResponse, RedirectResponse or StreamingResponse for other things.
    main.py
    import asyncio
from fastapi import FastAPI, Request
from fastapi.responses import (HTMLResponse, FileResponse, RedirectResponse,
                               StreamingResponse, PlainTextResponse)
from fastapi.staticfiles import StaticFiles
from fastapi.templating import Jinja2Templates

app = FastAPI()
app.mount("/static", StaticFiles(directory="static"), name="static")  # /static/logo.png
templates = Jinja2Templates(directory="templates")

@app.get("/hello", response_class=HTMLResponse)
def hello():
    return "<h1>Hello from FastAPI</h1>"

@app.get("/report")
def report():
    return FileResponse("report.pdf", filename="report.pdf")   # download

@app.get("/old")
def old():
    return RedirectResponse(url="/hello")

@app.get("/ping", response_class=PlainTextResponse)
def ping():
    return "pong"

@app.get("/stream")
async def stream():
    async def words():
        for w in ["Fast", "API ", "streams ", "like ", "ChatGPT"]:
            yield w + " "
            await asyncio.sleep(0.3)
    return StreamingResponse(words(), media_type="text/plain")

@app.get("/page/{name}", response_class=HTMLResponse)
def page(request: Request, name: str):
    return templates.TemplateResponse(request, "page.html", {"name": name})

    from fastapi.testclient import TestClient
from main import app, get_db

client = TestClient(app)

def test_root():
    r = client.get("/")
    assert r.status_code == 200
    assert r.json() == {"message": "Hello World"}

def test_create_todo():
    r = client.post("/todos", json={"title": "Write tests"})
    assert r.status_code == 201
    assert r.json()["title"] == "Write tests"

def test_validation_error():
    r = client.post("/todos", json={})          # title missing
    assert r.status_code == 422

def test_not_found():
    assert client.get("/todos/9999").status_code == 404

# Swap a real dependency for a fake one during tests
def fake_db():
    yield {"fake": True}

app.dependency_overrides[get_db] = fake_db

    Mini project: a complete Todo API ✅

    Everything together in one file: models, CRUD, status codes, errors, tags, a dependency. This is the API the mini Swagger in section 15 imitates.

    🥜 In a nutshell: Copy this into main.py, run fastapi dev main.py, open /docs, and play.
    main.py
    from typing import Annotated
from fastapi import Depends, FastAPI, HTTPException, Query, status
from pydantic import BaseModel, Field

app = FastAPI(title="Todo API", version="1.0.0")

# ---------- schemas ----------
class TodoCreate(BaseModel):
    title: str = Field(min_length=1, max_length=100)
    done: bool = False

class TodoUpdate(BaseModel):          # every field optional, for PATCH
    title: str | None = Field(default=None, min_length=1, max_length=100)
    done: bool | None = None

class Todo(TodoCreate):
    id: int

# ---------- "database" ----------
db: dict[int, Todo] = {}
counter = {"next": 1}

def get_todo_or_404(todo_id: int) -> Todo:          # reusable dependency
    if todo_id not in db:
        raise HTTPException(status.HTTP_404_NOT_FOUND, "Todo not found")
    return db[todo_id]

TodoDep = Annotated[Todo, Depends(get_todo_or_404)]

# ---------- routes ----------
@app.get("/")
def root():
    return {"message": "Hello World"}

@app.get("/todos", tags=["todos"])
def list_todos(done: bool | None = None,
               limit: Annotated[int, Query(ge=1, le=100)] = 20) -> list[Todo]:
    todos = list(db.values())
    if done is not None:
        todos = [t for t in todos if t.done == done]
    return todos[:limit]

@app.post("/todos", status_code=status.HTTP_201_CREATED, tags=["todos"])
def create_todo(data: TodoCreate) -> Todo:
    todo = Todo(id=counter["next"], **data.model_dump())
    db[todo.id] = todo
    counter["next"] += 1
    return todo

@app.get("/todos/{todo_id}", tags=["todos"])
def read_todo(todo: TodoDep) -> Todo:
    return todo

@app.put("/todos/{todo_id}", tags=["todos"])
def replace_todo(todo: TodoDep, data: TodoCreate) -> Todo:
    new = Todo(id=todo.id, **data.model_dump())
    db[todo.id] = new
    return new

@app.patch("/todos/{todo_id}", tags=["todos"])
def update_todo(todo: TodoDep, data: TodoUpdate) -> Todo:
    changes = data.model_dump(exclude_unset=True)    # only fields the client sent
    updated = todo.model_copy(update=changes)
    db[todo.id] = updated
    return updated

@app.delete("/todos/{todo_id}", status_code=status.HTTP_204_NO_CONTENT, tags=["todos"])
def delete_todo(todo: TodoDep):
    del db[todo.id]
