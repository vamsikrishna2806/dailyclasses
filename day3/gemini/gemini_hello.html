Google Gemini API

Hello World: one prompt to Gemini

1. Project structure

Each provider lives in its own folder with its own virtual environment, key file and library list.

D:\getwork\day3\ anthropic\ <- Claude (self-contained) gemini\ <- Gemini (self-contained) chatgpt\ <- ChatGPT (self-contained) gemini\ venv\ <- this folder's own virtual environment .env <- your secret key and model name requirements.txt <- libraries for this folder hello_gemini.py <- the program gemini_hello.html <- this guide
Why a venv per folder? Each folder can be copied or pushed to GitHub on its own, and its libraries never clash with the other providers.

2. What this program does

Sends one prompt to Gemini and prints the generated text.

StageWhat happens
1. Your scriptRuns the code line by line.
2. Keyload_dotenv() reads .env so the key is not typed in the code.
3. SDKgenai.Client() prepares the request for you.
4. RequestThe SDK sends client.models.generate_content(...) to Google's Gemini endpoint (generativelanguage.googleapis.com) with your key, which the SDK sends in a request header.
5. ModelThe AI reads your message and writes a reply on its server.
6. ReplyThe answer comes back as data; the SDK turns it into a Python object.
7. PrintYou extract the text with response.text and print it.
Key idea: your computer never runs the AI. It only sends a message over the internet and receives the answer. The key proves who is paying for the call, so keep it secret.

5. Setup (do once)

1

Get your key

Sign in at aistudio.google.com and create a Gemini API key (from Google AI Studio). Copy it and keep it private.

2

Put the key in this folder's .env

Open gemini\.env and replace the placeholder:

GEMINI_API_KEY=your-key-here
Never paste the key in chat, in code, or in GitHub. .gitignore blocks every .env file.
3

Create and activate this folder's virtual environment (once to create)

cd D:\getwork\day3\gemini
python -m venv venv
.\venv\Scripts\Activate.ps1

The prompt should start with (venv).

4

Install this folder's libraries (once, while venv is active)

pip install -r requirements.txt

6. Run it

cd D:\getwork\day3\gemini
python hello_gemini.py

Expected output

Model : gemini-2.5-flash
Reply : Hello, world! It's a pleasure to say hi to you today.

The reply text changes every time, but you should see the model name and a reply.

7. The full code

"""Hello World with the Google Gemini API."""
import os
from pathlib import Path

from dotenv import load_dotenv
from google import genai

# Read the .env file that sits next to this script
load_dotenv(Path(__file__).resolve().parent / ".env")

api_key = os.getenv("GEMINI_API_KEY")
model = os.getenv("GEMINI_MODEL", "gemini-2.5-flash")

if not api_key or api_key == "your-gemini-key-here":
    raise SystemExit("Add your GEMINI_API_KEY to the .env file first.")

client = genai.Client(api_key=api_key)

response = client.models.generate_content(
    model=model,
    contents="Say hello world in one friendly sentence.",
)

print("Model :", model)
print("Reply :", response.text)
