Day 3: Hello World with three AI APIs

Three tiny programs do the same job, each with a different AI company. Compare them to see that every AI API works the same way: key → client → send a message → read the reply.

Programs on this page
  1. hello_chatgpt.py (OpenAI)
  2. hello_gemini.py (Google Gemini)
  3. hello_anthropic.py (Claude)

The same 5 steps in all three programs

Each file: (1) loads the API key from a .env file next to the script, (2) stops early if the key is missing, (3) creates a client object, (4) sends one prompt, (5) prints the reply. Only the library name and the reply field change.

1. hello_chatgpt.py (OpenAI)

chatgpt/hello_chatgpt.py
What it does

Asks an OpenAI model to say hello world in one friendly sentence and prints the answer.

How to run
cd day3\chatgpt pip install -r requirements.txt python hello_chatgpt.py
The logic, step by step
  1. load_dotenv(...) reads chatgpt/.env so OPENAI_API_KEY becomes an environment variable. The key is never written in the code.
  2. os.getenv("OPENAI_MODEL", "gpt-4o-mini") picks the model, with a default if none is set.
  3. If the key is empty or still the placeholder text, raise SystemExit(...) stops with a clear message instead of a confusing error.
  4. client = OpenAI(api_key=api_key) creates the connection object.
  5. client.responses.create(model=..., input="Say hello world...") sends the prompt over the internet.
  6. response.output_text is the model's reply text, and the program prints it next to the model name.
Show the full source of chatgpt/hello_chatgpt.py (25 lines)
"""Hello World with the OpenAI API."""
import os
from pathlib import Path

from dotenv import load_dotenv
from openai import OpenAI

# Read the .env file that sits next to this script
load_dotenv(Path(__file__).resolve().parent / ".env")

api_key = os.getenv("OPENAI_API_KEY")
model = os.getenv("OPENAI_MODEL", "gpt-4o-mini")

if not api_key or api_key == "your-openai-key-here":
    raise SystemExit("Add your OPENAI_API_KEY to the .env file first.")

client = OpenAI(api_key=api_key)

response = client.responses.create(
    model=model,
    input="Say hello world in one friendly sentence.",
)

print("Model :", model)
print("Reply :", response.output_text)

"""Hello World with the Google Gemini API."""
import os
from pathlib import Path

from dotenv import load_dotenv
from google import genai

# Read the .env file that sits next to this script
load_dotenv(Path(__file__).resolve().parent / ".env")

api_key = os.getenv("GEMINI_API_KEY")
model = os.getenv("GEMINI_MODEL", "gemini-2.5-flash")

if not api_key or api_key == "your-gemini-key-here":
    raise SystemExit("Add your GEMINI_API_KEY to the .env file first.")

client = genai.Client(api_key=api_key)

response = client.models.generate_content(
    model=model,
    contents="Say hello world in one friendly sentence.",
)

print("Model :", model)
print("Reply :", response.text)

3. hello_anthropic.py (Claude)

anthropic/hello_anthropic.py
What it does

The same program for Anthropic's Claude models.

How to run
cd day3\anthropic pip install -r requirements.txt python hello_anthropic.py
The logic, step by step
  1. Loads ANTHROPIC_API_KEY from .env, exactly like the others.
  2. client.messages.create(...) needs two extra things: max_tokens=200 (the longest reply allowed) and the prompt as a messages list with role: "user".
  3. The reply is a list of content blocks, so the text is response.content[0].text.
Key idea: The messages=[{"role": "user", "content": ...}] format you see here is the one most chat APIs (and later LangChain) use.

"""Hello World with the Anthropic (Claude) API."""
import os
from pathlib import Path

from anthropic import Anthropic
from dotenv import load_dotenv

# Read the .env file that sits next to this script
load_dotenv(Path(__file__).resolve().parent / ".env")

api_key = os.getenv("ANTHROPIC_API_KEY")
model = os.getenv("ANTHROPIC_MODEL", "claude-haiku-5-5")

if not api_key or api_key == "your-anthropic-key-here":
    raise SystemExit("Add your ANTHROPIC_API_KEY to the .env file first.")

client = Anthropic(api_key=api_key)

response = client.messages.create(
    model=model,
    max_tokens=200,
    messages=[
        {"role": "user", "content": "Say hello world in one friendly sentence."}
    ],
)

print("Model :", model)
print("Reply :", response.content[0].text)
