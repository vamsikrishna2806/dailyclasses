LangGraph, explained simply

LangGraph in a Nutshell

LangGraph runs your AI app as a map. Data moves along the map, and the map can decide, loop, and pause. Press play and watch.

The five parts

Every LangGraph app is built from these five ideas. The rest of this page shows each one moving.

StateA shared notebook that every step can read and write.
NodesSteps. Each one is a function that does one job.
EdgesArrows that say which step runs next.
ConditionsA decision that picks the next arrow.
PausesStop and wait for a person, then carry on.

Watch the map run

A draft is written, checked, and rewritten until it is good. Then the graph pauses and waits for a person to approve it.

draft: none good: no approved: no
Press Play. The dot is the work moving through the map.

The notebook: state

Each step does not pass the whole work to the next one. It reads the notebook, changes only what it owns, and puts the notebook back. The chips above are that notebook: draft, good, and approved.

Nothing is hidden. Any step can see the current notebook, and a saved notebook lets a paused app continue later.

The same map, as code

Each line adds one of the five parts to the map above.

graph = StateGraph(State)                      # the notebook
graph.add_node("draft", draft)                 # a worker
graph.add_conditional_edges("check", route)    # the decision and its arrows
app = graph.compile(checkpointer=saver)        # saves the notebook so pauses work

This is an outline for learning, not a complete program. The full course has runnable examples.

In one sentence

LangGraph is a shared notebook passed along a map of steps, where arrows can decide, loop, and pause.
