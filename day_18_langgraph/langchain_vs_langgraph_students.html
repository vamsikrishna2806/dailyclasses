LangChain vs LangGraph

Both tools help you build AI apps. The difference is the shape of the work. Press the buttons and watch the shapes move.

LangChain

1. A straight line

LangChain connects steps in one fixed order. Data goes in one end and comes out the other. Each box runs once.

Order never changes.
Press the button to send a question through the line.
LangGraph

2. A map with loops and choices

LangGraph is a map. A step can ask a question (a decision), send you back to an earlier step (a loop), and keep a shared notebook called state that every step can read and write.

    Agentic loop

    3. The agentic loop

    An agent is an AI that can use tools. Its loop is simple: the model thinks, uses a tool if it needs one, reads the result, and thinks again. It stops when no tool is needed.

    Is the loop part of LangGraph? Not exactly. The loop is an idea (called ReAct) that you can build in any code. LangGraph is the tool that lets you draw that loop as a graph, with a clear way to stop.

    tool calls so far: 0 
      # The loop, written as a LangGraph graph
def should_continue(state):
    last = state["messages"][-1]
    return "tools" if last.tool_calls else END   # stop when no tool is needed

graph.add_conditional_edges("model", should_continue)
graph.add_edge("tools", "model")                 # the loop: result goes back

      The loop is the same in every agent. LangGraph gives you the wiring and the stop rule. It also has prebuilt helpers that set this loop up for you.

      Both are Python. Notice the difference in shape.

      LangChain: a pipe 
      chain = prompt | model | parser

      LangGraph: nodes and edges 
      graph = StateGraph(State)
graph.add_node("think", think)

      Remember this

      Use LangChain when
      • Steps always run in the same order
      • You need one question and one answer
      • You are building a simple RAG or prompt pipeline
      Use LangGraph when
      • The next step depends on the result
      • The app must loop until a goal is met (like an agent's tool loop)
      • You need a pause for a human, or several agents

      Good news: LangGraph uses LangChain's models and tools. You learn LangChain first, then add LangGraph when the work needs a map.
