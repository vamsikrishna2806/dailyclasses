Agentic architectures, in motion

Five ways to build an agent with LangGraph

An agent is a model that can call tools and decide what to do next. These five shapes cover most agent apps. Press Run on each to watch the graph move.

Model (agent) Tool Decision Other agent Waits for a person
1 · Single agent with tools (ReAct)

The model, a tool, and a loop

The model reads the question. If it needs a tool, it calls one, reads the result, and thinks again. When no tool is needed, it answers. Most agents in the day 17 folder use this shape.

Press Run.
agent = create_react_agent(llm, tools)   # the loop is built in
result = agent.invoke({"messages": [("user", "Weather in Pune?")]})
Use when one model needs a few tools and can decide which one to call next.
2 · Router

Sort the question, send it to one expert

A router reads the question once and picks one specialist. Only that specialist runs. There is no loop.

Press Run.
graph.add_conditional_edges("router", pick_specialist,
    {"weather": "weather", "money": "money", "recipes": "recipes"})
Use when the request has a clear type, and each type needs its own tools or prompt.
3 · Supervisor with workers

A boss delegates, and collects the reports

A supervisor agent splits the task. It sends parts to workers, gets each report back, and writes the final answer.

Press Run.
supervisor = create_supervisor([research, math, writer], model=llm)
Use when a task has several parts, and each part needs a different skill or set of tools.
4 · Reflection (write, critique, revise)

Write, get a critic's review, then fix it

One agent writes. A second agent, the critic, reviews it. If the review is not good, the writer revises. The loop stops when the critic is satisfied.

Press Run.
graph.add_conditional_edges("critic", lambda s: "send" if s["ok"] else "write",
    {"send": END, "write": "write"})
Use when the first answer is often weak, and a second pass with a checklist makes it better.
5 · Human in the loop

Pause for a person before the final step

The agent drafts the work, then stops. The graph waits until a person approves it. If it is not approved, the agent rewrites.

Press Run.
app = graph.compile(checkpointer=saver, interrupt_before=["send"])
app.invoke(input, config)          # pauses before "send"
app.invoke(None, config)           # a person approved; continue
Use when an action is hard to undo, such as sending an email, paying, or deleting data.
