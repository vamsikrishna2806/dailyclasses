LangChain for Kids 🦜

A beginner course that teaches you to build AI apps with Python: from asking a model one question, to an assistant that reads your own documents and uses tools. 23 lessons, each with a 3D animation, plain-language explanation, real code and a quiz.

▶ Start with lesson 01 📘 Open the concept guide

🤔 What is LangChain?

A large language model (LLM), such as the model behind ChatGPT, can write and answer questions, but it only knows what it was trained on. Real apps need more: your own documents, your own steps, and actions like calculations or lookups.

LangChain is a Python toolbox that connects those pieces. It is not an AI model itself. It gives you ready-made building blocks, so you write less glue code.

🧒 Your Python codethe app you write
→
🦜 LangChainthe toolbox: prompts, chains, memory, tools
→
🧠 LLMthe brain: OpenAI, Claude, or a local model
📚 Your documentsvia loaders, splitters, vector stores
🔧 Your functionsvia tools and agents

💡 Why learn it?

🧩 Less glue code

Prompts, models, parsers and memory fit together with one pipe | instead of hand-written plumbing.

📚 Answers from your data

Retrieval-Augmented Generation (RAG) makes the model answer from your files, with sources, instead of guessing.

🤖 Agents that act

Give the model tools, such as a calculator or a database lookup, and let it decide which one to use.

🛡️ Production habits

Tracing, retries and fallbacks teach you to debug and keep an app working when a model fails.

🧰 What you need before you start

🐍 Python 3.10+

Basic Python is enough: variables, functions, lists and dictionaries. Classes help in lessons 07 and 21.

🔑 An LLM key

An OpenAI or Anthropic API key, or a free local model with Ollama (lesson 01 shows both).

💻 An editor and a terminal

Any editor, such as VS Code. Windows PowerShell, Git Bash, or the Command Prompt all work.

💰 Cost: API calls are billed by use. The labs use small prompts, so a full run costs very little. Set a spending limit in your provider's dashboard. Lesson 12 and the ASCII/graph labs work offline.

⚙️ Set up once (virtual environment)

A virtual environment (.venv) is a private box of packages for this course, so it does not clash with other Python projects. Run these once in a terminal:

# 1. go to the examples folder
> cd D:\getwork\day13_langchain\langchain_examples
# 2. create the box (first time only)
> python -m venv .venv
# 3. switch it on (do this in every new terminal)
> .venv\Scripts\activate
# 4. install the course packages (first time only)
> pip install -r requirements.txt
# 5. copy the key file and add your key
> copy .env.example .env

Your prompt should start with (.venv) before you run any lesson. Mac and Linux users: use python3 -m venv .venv and source .venv/bin/activate.

🆘 Common problems and fixes

What you seeUsual causeFix
ModuleNotFoundError: langchain_openaiThe venv is not active, or packages are not installed.Run .venv\Scripts\activate, then pip install -r requirements.txt.
AuthenticationError or 401The key is missing or wrong in .env.Check .env is in the same folder as main.py. Restart the terminal after editing it.
RateLimitError or 429Too many requests in a short time.Wait a minute, run fewer items, or add a fallback (lesson 22).
KeyError in a promptA {blank} in the template has no value.Pass a value for every blank in invoke({...}).
ValidationErrorThe model's answer does not match the schema.Improve the Field(description=...) text, or retry (lesson 07).
RAG answers "I do not know" too oftenChunks are too small, k is too low, or the question is worded differently.Raise chunk_size or k, and test a few wordings (lessons 13 and 16).
The chatbot forgetsA different session_id is used, or none is passed.Pass the same config with the same session_id (lesson 11).
Recursion limit reachedAn agent loops without finishing.Make the tool descriptions clearer, and keep recursion_limit small (lesson 19).

📖 Words you will meet

LLM

Large language model: the AI that writes text.

Token

A small piece of text (about ¾ of a word). Models count and charge by tokens.

Prompt

The text you send to the model, including instructions.

Message

One turn in a chat, with a role: system, human or AI.

Chain

Steps joined with |, run in order.

Embedding

A list of numbers that represents the meaning of text.

Chunk

A piece of a long document, small enough to search and send.

Vector store

A store that finds the chunks closest in meaning to a question.

Retriever

A helper that takes a question and returns the best matching documents.

RAG

Retrieval-Augmented Generation: find text first, then answer from it.

Tool

A Python function the model is allowed to ask for.

Agent

A model that loops: think, use a tool, observe, repeat.

State and graph

In LangGraph: the shared data, and the nodes and edges that change it.

Callback

A hook that runs at each step, so you can watch what happens.

Trace

A recording of every step of a run, shown in LangSmith.

Pydantic

A library that checks data has the right shape and types.

🧠 Remember: the model does not remember anything between calls. Your app does: it stores the history, and sends it back.
