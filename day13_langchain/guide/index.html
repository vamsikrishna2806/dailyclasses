🧭 The big picture

Almost every LangChain app follows one of three shapes. Learn these first; every lesson fits one of them.

🔗 A chain

Fixed steps, same order every time: prompt → model → parser. Lessons 04–10.

chain = prompt | llm | parser

📚 A RAG app

Find the right text first, then answer from it. Lessons 12–17.

{"context": retriever | fmt,
 "question": passthrough}
  | prompt | llm | parser

🤖 An agent

The model decides which tool to use, looks at the result, and repeats. Lessons 18–19.

agent = create_agent(model, tools)

🧠 Simple mental models

🍳 Chain = a recipe

Each step gives its result to the next one. Nothing runs until you cook it (invoke).

📖 RAG = an open-book exam

The model is the student. Retrieval opens the right page before it answers.

🕵️ Agent = a detective

Think about the next clue, check it with a tool, learn, and repeat until the case is solved.

🧾 The shape of the code

Every lesson's main.py follows this order. Learn it once and the rest is repetition.

# 1. load settings (keys from .env)
load_dotenv()
# 2. build the parts: model, prompt, tools, store
llm = ChatOpenAI(model="gpt-4o-mini")
prompt = ChatPromptTemplate.from_template("...")
# 3. connect them
chain = prompt | llm | StrOutputParser()
# 4. run it
print(chain.invoke({"question": "..."}))
📌 Tip: when something breaks, check the pieces in order: the key, the packages, the prompt blanks, the retrieved chunks, then the model's answer. Lesson 21 shows how to see each piece.
