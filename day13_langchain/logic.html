2. 01 Setup

01_setup/main.py
What it does

Checks that the libraries are installed and that Ollama is running. It doesn't call any AI.

How to run
cd day13_langchain\langchain_example_ollama\01_setup python main.py
The logic, step by step
  1. Loops over the package names and prints importlib.metadata.version(pkg). A missing package prints the pip command that installs it.
  2. Reads OLLAMA_HOST (default http://localhost:11434).
  3. Opens <host>/api/tags with urlopen. If that works, Ollama is running; a URLError means start Ollama first.
Show the full source of 01_setup/main.py (29 lines)
"""01 · Setup & Environment

Run (with the venv active):  python main.py
Uses a free local model through Ollama. No API key needed.
Install Ollama from https://ollama.com, then run:  ollama pull llama3.2
"""

from importlib.metadata import version, PackageNotFoundError
from urllib.request import urlopen
from urllib.error import URLError
from dotenv import load_dotenv
import os

load_dotenv()  # optional: reads .env (for example OLLAMA_HOST)

for pkg in ["langchain", "langchain-core", "langchain-ollama"]:
    try:
        print(f"{pkg:<20} {version(pkg)}")
    except PackageNotFoundError:
        print(f"{pkg:<20} NOT INSTALLED -> pip install {pkg}")

host = os.getenv("OLLAMA_HOST", "http://localhost:11434")
print("Ollama host:", host)

try:
    with urlopen(f"{host}/api/tags", timeout=3) as resp:
        print("Ollama server is running, status:", resp.status)
except URLError:
    print("Ollama server NOT reachable -> start Ollama, then run: ollama pull llama3.2")

4. 03 Messages and roles

03_messages/main.py
What it does

Has a 2-turn conversation by keeping a list of messages.

How to run
cd day13_langchain\langchain_example_ollama\03_messages python main.py
The logic, step by step
  1. SystemMessage sets the behaviour ("friendly tutor, 2 sentences"), and HumanMessage is the question.
  2. After the first answer, the program appends the AIMessage and then a new HumanMessage.
  3. Sending the whole list again lets the model see the earlier turns. That is how chat "memory" works.
Show the full source of 03_messages/main.py (25 lines)
"""03 · Messages & Roles

Run (with the venv active):  python main.py
Uses a free local model through Ollama (run: ollama pull llama3.2). No API key needed.
"""

from dotenv import load_dotenv
from langchain_core.messages import SystemMessage, HumanMessage, AIMessage
from langchain_ollama import ChatOllama

load_dotenv()
llm = ChatOllama(model="llama3.2", temperature=0)

messages = [
    SystemMessage(content="You are a friendly tutor. Answer in 2 short sentences."),
    HumanMessage(content="What is a variable?"),
]
first = llm.invoke(messages)
print(first.content)

# Keep the conversation: add the reply, then the follow-up question
messages.append(AIMessage(content=first.content))
messages.append(HumanMessage(content="Give me an example in Python."))
second = llm.invoke(messages)
print(second.content)

8. 07 Structured output (Pydantic)

07_structured_output/main.py
What it does

Gets a checked Python object back instead of text.

How to run
cd day13_langchain\langchain_example_ollama\07_structured_output python main.py
The logic, step by step
  1. class Person(BaseModel) has name, age and city. Each Field(description=...) tells the model what to put in that field.
  2. llm.with_structured_output(Person).invoke("Ravi Kumar is 25...") returns a Person object, so person.age + 1 works.
  3. Person(age="twenty") raises a ValidationError, which shows that Pydantic checks the types.
Show the full source of 07_structured_output/main.py (28 lines)
"""07 · Structured Output (Pydantic)

Run (with the venv active):  python main.py
Uses a free local model through Ollama (run: ollama pull llama3.2). No API key needed.
"""

from dotenv import load_dotenv
from pydantic import BaseModel, Field, ValidationError
from langchain_ollama import ChatOllama

load_dotenv()

class Person(BaseModel):
    name: str = Field(description="full name of the person")
    age: int = Field(description="age in whole years")
    city: str | None = Field(default=None, description="city, if mentioned")

llm = ChatOllama(model="llama3.2", temperature=0)
person = llm.with_structured_output(Person).invoke(
    "Ravi Kumar is 25 and lives in Hyderabad."
)
print(person)
print("Next year he will be", person.age + 1)

try:
    Person(name="Ravi", age="twenty")
except ValidationError as e:
    print("Validation caught", e.error_count(), "error(s)")

10. 09 Runnable building blocks

09_runnable_primitives/main.py
What it does

Splits one input into parallel jobs, passes values through, and picks keys.

How to run
cd day13_langchain\langchain_example_ollama\09_runnable_primitives python main.py
The logic, step by step
  1. RunnableParallel(praise=..., criticism=..., verdict=...) runs 3 small chains on the same movie, and the result is a dict with 3 keys.
  2. RunnableLambda(show) wraps a normal Python function so it can go inside a chain.
  3. RunnablePassthrough() passes the input on unchanged, next to new computed values.
  4. {"topic": itemgetter("subject")} takes one key out of a bigger input.
Show the full source of 09_runnable_primitives/main.py (38 lines)
"""09 · Runnable Building Blocks

Run (with the venv active):  python main.py
Uses a free local model through Ollama (run: ollama pull llama3.2). No API key needed.
"""

from operator import itemgetter
from dotenv import load_dotenv
from langchain_core.output_parsers import StrOutputParser
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.runnables import RunnableLambda, RunnableParallel, RunnablePassthrough
from langchain_ollama import ChatOllama

load_dotenv()
llm = ChatOllama(model="llama3.2", temperature=0)

def make(instr):
    return ChatPromptTemplate.from_template(instr + " the movie {movie}.") | llm | StrOutputParser()

# Fork: three answers from one input
panel = RunnableParallel(
    praise=make("Write a 1-line praise review for"),
    criticism=make("Write a 1-line criticism for"),
    verdict=make("Give a one-word verdict for"),
)

def show(d: dict) -> str:
    return "\n".join(f"== {k.upper()} ==\n{v}" for k, v in d.items())

print((panel | RunnableLambda(show)).invoke({"movie": "Inception"}))

# Passthrough: keep the question and add its length
demo = RunnableParallel(question=RunnablePassthrough(), length=lambda x: len(x["question"]))
print(demo.invoke({"question": "hello"}))

# itemgetter: pick one key from a larger input
pick = {"topic": itemgetter("subject")} | ChatPromptTemplate.from_template("Write a haiku about {topic}") | llm | StrOutputParser()
print(pick.invoke({"subject": "rain", "extra": "ignored"}))

11. 10 Streaming and batching

10_streaming/main.py
What it does

Prints the answer while it is being written, and runs many inputs at once.

How to run
cd day13_langchain\langchain_example_ollama\10_streaming python main.py
The logic, step by step
  1. for chunk in chain.stream(...) prints each piece as it arrives. The program also measures how long the first piece took.
  2. async for chunk in chain.astream(...) is the async version, used in web servers.
  3. chain.batch([...]) runs several inputs and keeps the results in the same order.
Show the full source of 10_streaming/main.py (33 lines)
"""10 · Streaming & Batching

Run (with the venv active):  python main.py
Uses a free local model through Ollama (run: ollama pull llama3.2). No API key needed.
"""

import asyncio, time
from dotenv import load_dotenv
from langchain_core.output_parsers import StrOutputParser
from langchain_core.prompts import ChatPromptTemplate
from langchain_ollama import ChatOllama

load_dotenv()
chain = ChatPromptTemplate.from_template("Write a 4-line poem about {thing}.") | ChatOllama(model="llama3.2") | StrOutputParser()

# 1. Streaming: print as tokens arrive
start = time.perf_counter()
for i, chunk in enumerate(chain.stream({"thing": "the sea"})):
    if i == 0:
        print(f"[first chunk after {time.perf_counter() - start:.2f}s]")
    print(chunk, end="", flush=True)
print()

# 2. Async streaming (for web apps)
async def main():
    async for chunk in chain.astream({"thing": "the sky"}):
        print(chunk, end="", flush=True)
    print()

asyncio.run(main())

# 3. Batch: many inputs, results in the same order
print(chain.batch([{"thing": "rain"}, {"thing": "fire"}]))

11_chat_memory/main.py
What it does

Remembers each user's conversation separately.

How to run

The logic, step by step
  1. store is a dictionary that maps a session id to an InMemoryChatMessageHistory.

"""11 · Chat Memory

Run (with the venv active):  python main.py
Uses a free local model through Ollama (run: ollama pull llama3.2). No API key needed.
"""

from dotenv import load_dotenv
from langchain_core.chat_history import InMemoryChatMessageHistory
from langchain_core.output_parsers import StrOutputParser
from langchain_core.prompts import ChatPromptTemplate, MessagesPlaceholder
from langchain_core.runnables.history import RunnableWithMessageHistory
from langchain_ollama import ChatOllama

load_dotenv()
store = {}

def get_session_history(session_id: str):
    if session_id not in store:
        store[session_id] = InMemoryChatMessageHistory()
    return store[session_id]

prompt = ChatPromptTemplate.from_messages([
    ("system", "You are a friendly assistant."),
    MessagesPlaceholder(variable_name="history"),
    ("human", "{question}"),
])
chain = prompt | ChatOllama(model="llama3.2", temperature=0) | StrOutputParser()
chat = RunnableWithMessageHistory(
    chain, get_session_history,
    input_messages_key="question", history_messages_key="history",
)

alice = {"configurable": {"session_id": "alice"}}
bob = {"configurable": {"session_id": "bob"}}

chat.invoke({"question": "My name is Ravi."}, config=alice)
print(chat.invoke({"question": "What is my name?"}, config=alice))  # Ravi
print(chat.invoke({"question": "What is my name?"}, config=bob))    # does not know

15. 14 Embeddings

14_embeddings/main.py
What it does

Turns sentences into vectors (lists of numbers), where similar meaning gives similar numbers.

How to run
cd day13_langchain\langchain_example_ollama\14_embeddings python main.py
The logic, step by step
  1. OllamaEmbeddings(model="nomic-embed-text") is the embedding model.
  2. embed_documents(sentences) gives one vector per sentence, and embed_query(question) gives one for the question.
  3. cosine(a, b) measures how close two vectors are (1 means the same meaning).
  4. The program sorts the sentences by score. The stock-market sentences rank above the cake sentences for "Why are investors worried?", even though they share no words.
Show the full source of 14_embeddings/main.py (29 lines)
"""14 · Embeddings

Run (with the venv active):  python main.py
Uses a free local embedding model through Ollama (run: ollama pull nomic-embed-text).
No API key needed.
"""

import math
from dotenv import load_dotenv
from langchain_ollama import OllamaEmbeddings

load_dotenv()
emb = OllamaEmbeddings(model="nomic-embed-text")

def cosine(a, b):
    dot = sum(x * y for x, y in zip(a, b))
    return dot / (math.sqrt(sum(x * x for x in a)) * math.sqrt(sum(y * y for y in b)))

sentences = [
    "The stock market fell today.",
    "Shares dropped sharply.",
    "I love baking cakes.",
    "Bread needs flour and yeast.",
]
vectors = emb.embed_documents(sentences)
query = emb.embed_query("Why are investors worried?")

for score, s in sorted(((cosine(query, v), s) for v, s in zip(vectors, sentences)), reverse=True):
    print(round(score, 3), s)

21. 20 LangGraph basics

What it does

A tiny graph of plain Python steps. No AI.

How to run
cd day13_langchain\langchain_example_ollama\20_langgraph_intro python main.py
The logic, step by step
  1. State is a TypedDict with text and count. Every node reads the state and returns the keys it changes.
  2. clean strips spaces, then count_words counts the words.
  3. add_conditional_edges("count", route, ...): the route function picks the next node ("long" or "short").
  4. graph.invoke({...}) runs START → clean → count → END and returns the final state.
Show the full source of 20_langgraph_intro/main.py (31 lines)
"""20 · LangGraph Basics

Run (with the venv active):  python main.py
No model or API key needed (this lesson uses plain Python steps).
"""

from typing import TypedDict
from langgraph.graph import StateGraph, START, END

class State(TypedDict):
    text: str
    count: int

def clean(state: State):
    return {"text": state["text"].strip()}

def count_words(state: State):
    return {"count": len(state["text"].split())}

def route(state: State) -> str:
    return "long" if state["count"] > 5 else "short"

builder = StateGraph(State)
builder.add_node("clean", clean)
builder.add_node("count", count_words)
builder.add_edge(START, "clean")
builder.add_edge("clean", "count")
builder.add_conditional_edges("count", route, {"long": END, "short": END})

graph = builder.compile()
print(graph.invoke({"text": "  hello big world  ", "count": 0}))

"""22 · Errors, Retries & Fallbacks

Run (with the venv active):  python main.py
Uses two free local models through Ollama. No API key needed:
  ollama pull llama3.2     (primary)
  ollama pull qwen2.5      (backup, used if the primary fails)

import json
from dotenv import load_dotenv
from langchain_ollama import ChatOllama

load_dotenv()

primary = ChatOllama(model="llama3.2", temperature=0)
backup = ChatOllama(model="qwen2.5", temperature=0)  # any other model you have pulled
robust = primary.with_fallbacks([backup])

def get_json(prompt: str, attempts: int = 3) -> dict:
    for _ in range(attempts):
        text = robust.invoke(prompt).content
        try:
            return json.loads(text)
        except json.JSONDecodeError as e:
            prompt = f"Your last answer was not valid JSON ({e}). Return ONLY valid JSON."
    raise ValueError("Model never returned valid JSON")

try:
    print(get_json('Return JSON with keys "city" and "country" for Paris.'))
except Exception as e:
    print("Sorry, the assistant is busy. Please try again.", type(e).__name__)

24. 23 Capstone: Study Buddy agent

23_capstone/main.py
What it does

An agent that answers from your own notes and can do arithmetic, with short-term memory.

How to run
cd day13_langchain\langchain_example_ollama\23_capstone python main.py
The logic, step by step
  1. build_store() loads every .txt file in notes/, splits it into 500-character chunks, and embeds them into a vector store.
  2. Tool search_notes runs a similarity search (k=3) and returns the passages with their file name.
  3. Tool calculate allows only the characters 0-9 + - * / ( ) and then uses eval. That is safe only because of the filter.
  4. create_agent gets a system prompt: search before answering, cite the file, and say so when the notes don't have the answer.
  5. ask() keeps a history list and sends the last 10 messages, so "Explain that more simply" knows what "that" means. recursion_limit: 8 stops endless loops.
Show the full source of 23_capstone/main.py (68 lines)
"""23 · Capstone: Study Buddy Agent

Run (with the venv active):  python main.py
Put your .txt study notes in a notes/ folder next to main.py before running.
Uses free local models through Ollama:
  ollama pull llama3.2
  ollama pull nomic-embed-text
"""

from pathlib import Path
from dotenv import load_dotenv
from langchain.agents import create_agent
from langchain_community.document_loaders import TextLoader
from langchain_core.tools import tool
from langchain_core.vectorstores import InMemoryVectorStore
from langchain_ollama import ChatOllama, OllamaEmbeddings
from langchain_text_splitters import RecursiveCharacterTextSplitter

load_dotenv()

# 1. Ingest: put your .txt study notes in a folder called notes/ first
def build_store(folder="notes"):
    docs = []
    for path in Path(folder).glob("*.txt"):
        docs += TextLoader(str(path), encoding="utf-8").load()
    chunks = RecursiveCharacterTextSplitter(chunk_size=500, chunk_overlap=50).split_documents(docs)
    store = InMemoryVectorStore(OllamaEmbeddings(model="nomic-embed-text"))
    store.add_documents(chunks)
    return store

store = build_store()

# 2. Tools
@tool
def search_notes(query: str) -> str:
    """Search the student's study notes. Use this for any course question."""
    hits = store.similarity_search(query, k=3)
    return "\n\n".join(f"[{d.metadata.get('source')}] {d.page_content}" for d in hits)

@tool
def calculate(expression: str) -> str:
    """Evaluate simple arithmetic like '12 * (3 + 4)'."""
    if not set(expression) <= set("0123456789+-*/(). "):
        return "Only numbers and + - * / ( ) are allowed."
    return str(eval(expression))  # safe only because the input is filtered above

# 3. Agent
SYSTEM = ("You are a Study Buddy. Call search_notes before answering course questions. "
          "Cite the source file. If the notes do not contain the answer, say so. "
          "Use calculate for arithmetic.")
agent = create_agent(
    model=ChatOllama(model="llama3.2", temperature=0),
    tools=[search_notes, calculate],
    system_prompt=SYSTEM,
)

# 4. Memory: keep the last 10 messages
history = []

def ask(question: str) -> str:
    history.append({"role": "user", "content": question})
    result = agent.invoke({"messages": history[-10:]}, config={"recursion_limit": 8})
    answer = result["messages"][-1].content
    history.append({"role": "assistant", "content": answer})
    return answer

print(ask("What is photosynthesis?"))
print(ask("Explain that more simply."))
