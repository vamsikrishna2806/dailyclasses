How Ollama uses an MCP server

Three helpers work together. Press Next to see each step.

🐍
Python programthe messenger
🧠
Ollamathe brain
🧰
MCP serverthe toolbox
1
🐍 → 🧰

Python asks the toolbox: What tools do you have?
The toolbox answers: I have 3 tools, for example ask_wiki_question.

tools = await session.list_tools()
2
🐍 → 🧠

Python gives the brain your question and the list of tools.
What is the repo python-sdk about? You may use these tools.

reply = ollama.chat(model, messages, tools=ollama_tools)
3
🧠 → 🐍

The brain cannot use tools by itself, so it asks Python:
Please run ask_wiki_question for me.

reply.message.tool_calls
4
🐍 → 🧰 → 🐍

Python runs the tool on the toolbox (over the internet) and gets the result back.

result = await session.call_tool(name, args)
5
🐍 → 🧠 → you

Python gives the result to the brain. Now the brain knows the facts and writes the final answer.

final = ollama.chat(model, messages)
Remember: the brain 🧠 decides which tool to use, Python 🐍 runs it, and the MCP server 🧰 has the tools.
