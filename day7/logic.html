Day 7: Flask vs FastAPI (the same API twice)

Both files build the same Task API: list, create, get one, delete. Tasks are stored in a Python list in memory. Read them side by side.

1. flask_app/app.py

flask_app/app.py
What it does

Task API in Flask. Every input rule is checked by hand.

How to run
cd day7\flask_app python app.py # http://127.0.0.1:5000/tasks
The logic, step by step
  1. tasks = [] is the "database" and next_id counts up for each new task.
  2. POST /tasks reads the JSON body, then checks each rule itself: title present, 200 characters or fewer, priority a whole number from 1 to 5. Each failed rule returns its own 400 error.
  3. isinstance(priority, bool) is needed because in Python True counts as the number 1. Without it, true would sneak through as a priority.
  4. GET /tasks/<int:task_id> loops through the list and returns 404 if the task isn't found.

"""
Day 7 - Task API built with FLASK.

It does exactly the same job as ../fastapi_app/main.py so you can compare
the two files line by line.

Run:   python app.py
Open:  http://127.0.0.1:5000/tasks
"""
from flask import Flask, jsonify, request

app = Flask(__name__)

tasks = []      # our "database" (a plain Python list in memory)
next_id = 1


@app.get("/tasks")
def list_tasks():
    return jsonify(tasks)


@app.post("/tasks")
def create_task():
    global next_id
    data = request.get_json(silent=True) or {}

    # Flask does NOT check the input for you.
    # Every rule below is written by hand.
    title = data.get("title")
    if not isinstance(title, str) or not title.strip():
        return jsonify({"error": "title is required"}), 400
    if len(title.strip()) > 200:
        return jsonify({"error": "title must be 200 characters or less"}), 400

    priority = data.get("priority", 3)
    # bool is a subclass of int in Python, so True would sneak through without this
    if isinstance(priority, bool) or not isinstance(priority, int):
        return jsonify({"error": "priority must be a whole number"}), 400
    if not 1 <= priority <= 5:
        return jsonify({"error": "priority must be from 1 to 5"}), 400

    task = {"id": next_id, "title": title.strip(), "priority": priority, "done": False}
    tasks.append(task)
    next_id += 1
    return jsonify(task), 201


@app.get("/tasks/<int:task_id>")
def get_task(task_id):
    for task in tasks:
        if task["id"] == task_id:
            return jsonify(task)
    return jsonify({"error": "task not found"}), 404


@app.delete("/tasks/<int:task_id>")
def delete_task(task_id):
    for task in tasks:
        if task["id"] == task_id:
            tasks.remove(task)
            return "", 204
    return jsonify({"error": "task not found"}), 404


if __name__ == "__main__":
    app.run(debug=True, port=5000)

2. fastapi_app/main.py

fastapi_app/main.py
What it does

The same API in FastAPI. The rules live in a Pydantic model, and FastAPI checks them for you.

How to run
cd day7\fastapi_app fastapi dev main.py # http://127.0.0.1:8000/docs
The logic, step by step
  1. class TaskIn(BaseModel) states the rules once: title: str = Field(min_length=1, max_length=200) and priority: int = Field(default=3, ge=1, le=5).
  2. def create_task(task_in: TaskIn): because the parameter has the type TaskIn, FastAPI reads the JSON body, checks every rule, and answers 422 by itself if one fails.
  3. Task(id=next_id, **task_in.model_dump()) builds the stored task from the checked input.
  4. raise HTTPException(404, ...) replaces Flask's return jsonify(...), 404.
  5. The return type (-> Task, -> list[Task]) tells FastAPI what the answer looks like, and that shows up in the /docs page.
Key idea: Flask needs 12 lines of hand-written checks. FastAPI needs 2 lines of type hints, and you get interactive documentation at /docs for free.

"""
Day 7 - Task API built with FASTAPI.

It does exactly the same job as ../flask_app/app.py so you can compare
the two files line by line.

Run:   fastapi dev main.py        (or: uvicorn main:app --reload)
Open:  http://127.0.0.1:8000/docs  <- free interactive docs!
"""
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel, ConfigDict, Field

app = FastAPI(title="Task API", version="1.0")


# The rules live in the type hints. FastAPI + Pydantic check them for you.
class TaskIn(BaseModel):
    model_config = ConfigDict(str_strip_whitespace=True)

    title: str = Field(min_length=1, max_length=200)
    priority: int = Field(default=3, ge=1, le=5)


class Task(TaskIn):
    id: int
    done: bool = False


tasks: list[Task] = []   # our "database" (a plain Python list in memory)
next_id = 1


@app.get("/tasks")
def list_tasks() -> list[Task]:
    return tasks


@app.post("/tasks", status_code=201)
def create_task(task_in: TaskIn) -> Task:
    global next_id
    task = Task(id=next_id, **task_in.model_dump())
    tasks.append(task)
    next_id += 1
    return task


@app.get("/tasks/{task_id}")
def get_task(task_id: int) -> Task:
    for task in tasks:
        if task.id == task_id:
            return task
    raise HTTPException(status_code=404, detail="task not found")


@app.delete("/tasks/{task_id}", status_code=204)
def delete_task(task_id: int) -> None:
    for task in tasks:
        if task.id == task_id:
            tasks.remove(task)
            return
    raise HTTPException(status_code=404, detail="task not found")
