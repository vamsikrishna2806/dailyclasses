Mini Project Prompts: Mix & Match the Stack

12 small, beginner-friendly apps. Each one combines a different frontend, backend and database from the Full-Stack Layers Guide.

How to use these prompts
  1. Pick a project (use the filters to find a technology you want to practise).
  2. Click Copy prompt and paste it into Claude, ChatGPT or any AI coding assistant, or use it as a written brief to build it yourself.
  3. Run the app, then read every file and find which layer each line belongs to: frontend, backend or persistence.
  4. Try the "Stretch goal" at the end of each prompt once the basic version works.
