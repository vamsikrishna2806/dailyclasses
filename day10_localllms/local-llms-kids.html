AI that lives on your computer

A local LLM is a chatbot brain you download and run on your own Windows PC. No internet needed, nothing sent to anyone. This page shows what it is, when to use it, every model you can download, and how to install and use 11 Windows apps that run them.

Stop 1

What is a local LLM?

An LLM (Large Language Model) is the brain behind chatbots like ChatGPT, Claude and Gemini. Usually that brain lives in a giant data centre: your question travels over the internet, gets answered there, and travels back. That is cloud AI.

A local LLM is a model whose files you download to your own computer and run there. Your question never leaves your machine. It works on a plane, in a village with no signal, and inside a hospital where data must stay private.

This is possible because companies like Meta, Google, Alibaba, Mistral, Microsoft, DeepSeek and OpenAI publish open-weight models: the trained "brain file" is free to download. Clever compression (quantization) makes them small enough for a normal laptop.

Magic words you will hear

WordSimple meaningExample
Parameters (B)The number of tiny "knobs" inside the brain. More knobs usually means smarter but heavier.8B = 8 billion knobs
Open weightsThe trained brain file is free to download and run yourself.Llama, Gemma, Qwen, gpt-oss
QuantizationShrinking the brain by storing each knob with fewer bits, like compressing a photo. Slightly less sharp, much smaller.Q4 is about 4× smaller than full size
GGUFThe most common file format for local models (used by llama.cpp, Ollama, LM Studio).gemma-3-4b-it-Q4_K_M.gguf
RAM / VRAMComputer memory / graphics-card memory. The model must fit inside to run. VRAM is much faster.16 GB RAM, 8 GB VRAM
Tokens per secondHow fast words appear. 10+ feels comfortable to read.35 tok/s on a gaming GPU
Context windowHow much text the model can remember in one chat.8K, 32K, 128K tokens
Inference engineThe program that actually runs the model.llama.cpp, Ollama, vLLM, MLX
Instruct / chat modelA version trained to follow instructions and chat (the one you usually want).-instruct, -it
MoEMixture of Experts: a big model where only a few "expert" parts wake up for each word, so it runs faster than its size suggests.gpt-oss, Qwen3-30B-A3B, Llama 4
LicenseThe rules for using the model. Some allow anything, some limit commercial use.Apache 2.0, MIT, Llama license, Gemma terms
Handy rule

At Q4 compression, a model needs roughly 0.6 GB of memory per billion parameters, plus about 1 GB extra. So an 8B model needs about 6 GB, and a 70B model needs about 43 GB.

When should you use a local LLM?

Great times to go local

  • Private or secret data: medical notes, legal files, company code, personal diaries.
  • No or bad internet: flights, remote areas, factories, ships, air-gapped labs.
  • Learning and experimenting: try many models for free, no API key, no bill.
  • High volume, simple tasks: tagging, summarising or classifying thousands of documents.
  • Local RAG: a private "chat with my PDFs" (see the RAG guides in this folder).
  • Building products that must work offline, or edge devices like robots and kiosks.
  • Rules and compliance that say data must stay in your country or building.

Better to use the cloud when

  • You need the smartest possible answers (hard reasoning, long complex coding, research).
  • Your computer is weak (old laptop, 8 GB RAM or less, no GPU) and you need speed.
  • You serve many users at once and don't want to run GPU servers.
  • You need very long context, top-quality vision, voice or tools out of the box.

Many teams use both: local for private and simple jobs, cloud for the hardest ones.

Will it run on my computer?

The model must fit in memory. A graphics card (GPU) with its own memory (VRAM) makes it fast. Without a GPU it still runs on the CPU, just slower. On Windows, an NVIDIA RTX card is the easiest fast option; recent AMD Radeon and Intel Arc cards also work with Ollama and LM Studio.

Install and use on Windows

Before you start: check your PC

Open PowerShell: press the Windows key, type PowerShell, press Enter. Then paste these one at a time.

# How much memory (RAM) do I have, in GB?
[math]::Round((Get-CimInstance Win32_ComputerSystem).TotalPhysicalMemory / 1GB)

# Which graphics card do I have?
Get-CimInstance Win32_VideoController | Select-Object Name

# NVIDIA cards only: exact graphics memory (VRAM) and driver
nvidia-smi

# How much free space is on drive C:, in GB?
[math]::Round((Get-PSDrive C).Free / 1GB)
  • No PowerShell? Use Settings → System → About for RAM and Task Manager → Performance → GPU for graphics memory.
  • Update your graphics driver first (NVIDIA app, AMD Adrenalin or Intel Arc control). An old driver is the top reason the GPU is not used.
  • Keep at least 20 GB free. Each model is 1 to 40+ GB.
  • winget (the Windows package manager) comes with Windows 11 and recent Windows 10. Check with winget --version.

      Ollama cheat sheet

      CommandWhat it does

      From PowerShell (no extra installs)

      $body = @{
  model    = "llama3.2"
  messages = @(@{ role = "user"; content = "Explain a local LLM to a 10 year old" })
  stream   = $false
} | ConvertTo-Json -Depth 5

$r = Invoke-RestMethod -Uri http://localhost:11434/api/chat -Method Post -Body $body -ContentType "application/json"
$r.message.content

      From Python

      # Install Python once:  winget install Python.Python.3.12
# Then:                 py -m pip install ollama
import ollama

reply = ollama.chat(
    model="llama3.2",
    messages=[{"role": "user", "content": "Give me 3 fun facts about space"}],
)
print(reply["message"]["content"])

      One code for every app (OpenAI format)

      Most Windows apps speak the OpenAI API format. Change only base_url to switch apps.

      # py -m pip install openai
from openai import OpenAI

BASE = {
    "ollama":    "http://localhost:11434/v1",
    "lmstudio":  "http://localhost:1234/v1",
    "jan":       "http://localhost:1337/v1",
    "gpt4all":   "http://localhost:4891/v1",
    "llamacpp":  "http://localhost:8080/v1",
    "koboldcpp": "http://localhost:5001/v1",
}

client = OpenAI(base_url=BASE["ollama"], api_key="not-needed")   # local apps ignore the key
r = client.chat.completions.create(
    model="qwen3:8b",          # use the model name your app shows
    messages=[{"role": "user", "content": "Hello from Windows!"}],
)
print(r.choices[0].message.content)

      Bonus: a 100% local RAG on Windows

      Combine this with the RAG guide: local embeddings + local chat model, so your documents never leave your PC.

      # ollama pull nomic-embed-text ; ollama pull llama3.2 ; py -m pip install ollama numpy
import ollama, numpy as np

docs = ["Employees get 24 days of paid leave per year.",
        "Reset your password from the self-service portal."]
vecs = np.array(ollama.embed(model="nomic-embed-text", input=docs)["embeddings"])

question = "How many leave days do I get?"
q = np.array(ollama.embed(model="nomic-embed-text", input=[question])["embeddings"][0])
scores = vecs @ q / (np.linalg.norm(vecs, axis=1) * np.linalg.norm(q))
best = docs[int(scores.argmax())]

answer = ollama.chat(model="llama3.2", messages=[{"role": "user",
    "content": f"Answer only from this context:\n{best}\n\nQuestion: {question}"}])
print(answer["message"]["content"])

      Tips, fixes and a quiz

      ProblemFix
      Very slow answersUse a smaller model (3B or 4B) or a smaller quantization; close heavy apps; update GPU drivers so the GPU is used.
      Out of memory / crashThe model is too big. Pick fewer parameters, or lower num_ctx.
      Disk is fullModels are 1–40+ GB each. Run ollama list and ollama rm the ones you don't use, or move storage with the OLLAMA_MODELS setting.
      Forgets long chatsIncrease context with /set parameter num_ctx 8192 (uses more memory).
      Wrong or made-up factsSmall models hallucinate more. Use a bigger model or add RAG with your documents.
      Can't connect from codeMake sure Ollama is running (ollama serve or the tray app) and use http://localhost:11434.
      Stay safe

      Download models only from trusted places (Ollama library, official Hugging Face pages). Don't expose port 11434 to the internet: by default Ollama listens only on your own computer, so keep it that way unless you add a login in front of it.
