Day 6: Task manager with Flask and SQLite

A full web app in 3 layers: a browser page (static/app.js), a Flask API (app.py), and a SQLite database (database.py).

Programs on this page
  1. database.py: all the SQL
  2. app.py: the Flask API
  3. static/app.js: the page logic

How the 3 files work together

The browser never touches the database. It calls the API; the API checks the input; database.py runs SQL.

browser (app.js) ──fetch /api/tasks──▶ Flask (app.py) ──function call──▶ database.py ──SQL──▶ tasks.db

1. database.py: all the SQL

database.py
What it does

Creates the tasks table and has one function for each action: list, add, toggle done, delete.

The logic, step by step
  1. get_db_connection() opens tasks.db. Setting row_factory = sqlite3.Row lets you read a column by name, like row['title'].
  2. init_db() runs CREATE TABLE IF NOT EXISTS tasks (id, title, done, created_at), so the table is created the first time and left alone after that.
  3. get_all_tasks() runs SELECT ... ORDER BY id DESC (newest first) and turns each row into a Python dictionary.
  4. add_task(title) runs INSERT ... VALUES (?, 0, ?). The ? placeholders keep user text out of the SQL itself, which prevents SQL injection. It then returns the new task, using cursor.lastrowid as its id.
  5. toggle_task(id) first SELECTs the task (and returns None if it doesn't exist), then flips done between 0 and 1 with an UPDATE.
  6. delete_task(id) runs DELETE and returns True only if a row was actually removed (cursor.rowcount > 0).

import sqlite3
from datetime import datetime

# Name of the SQLite database file stored locally
DATABASE_NAME = "tasks.db"


def get_db_connection():
    """
    Connect to the SQLite database file.
    Row factory allows accessing query results by column name like dictionaries (e.g., row['title']).
    """
    conn = sqlite3.connect(DATABASE_NAME)
    conn.row_factory = sqlite3.Row
    return conn


def init_db():
    """
    Creates the 'tasks' table automatically if it does not already exist.
    Columns:
      - id: unique number for each task, auto-increments
      - title: text description of the task (required)
      - done: integer flag (0 = not done, 1 = done, defaults to 0)
      - created_at: readable timestamp string showing when the task was added
    """
    conn = get_db_connection()
    cursor = conn.cursor()

    cursor.execute("""
        CREATE TABLE IF NOT EXISTS tasks (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            title TEXT NOT NULL,
            done INTEGER NOT NULL DEFAULT 0,
            created_at TEXT NOT NULL
        );
    """)

    conn.commit()
    conn.close()


def get_all_tasks():
    """
    Fetch all tasks from the database, sorted newest first (highest id first).
    Returns a list of task dictionaries.
    """
    conn = get_db_connection()
    cursor = conn.cursor()

    # Query all tasks ordered newest first using parameterized SQL (best practice)
    cursor.execute("SELECT id, title, done, created_at FROM tasks ORDER BY id DESC")
    rows = cursor.fetchall()
    conn.close()

    # Convert each sqlite3.Row object into a standard Python dictionary
    tasks = []
    for row in rows:
        tasks.append({
            "id": row["id"],
            "title": row["title"],
            "done": row["done"],
            "created_at": row["created_at"]
        })
    return tasks


def add_task(title):
    """
    Insert a new task into the database using a parameterized query (?).
    Returns the newly created task dictionary.
    """
    conn = get_db_connection()
    cursor = conn.cursor()

    # Current timestamp formatted as YYYY-MM-DD HH:MM:SS
    created_at = datetime.now().strftime("%Y-%m-%d %H:%M:%S")

    # Use the '?' placeholder to safely pass user input and prevent SQL injection
    cursor.execute(
        "INSERT INTO tasks (title, done, created_at) VALUES (?, 0, ?)",
        (title, created_at)
    )

    new_id = cursor.lastrowid
    conn.commit()
    conn.close()

    return {
        "id": new_id,
        "title": title,
        "done": 0,
        "created_at": created_at
    }


def toggle_task(task_id):
    """
    Toggle a task's 'done' status between 0 (not done) and 1 (done).
    Uses a parameterized query (?) with the task ID.
    Returns the updated task dictionary, or None if the task does not exist.
    """
    conn = get_db_connection()
    cursor = conn.cursor()

    # Check if the task exists first
    cursor.execute("SELECT id, title, done, created_at FROM tasks WHERE id = ?", (task_id,))
    row = cursor.fetchone()

    if row is None:
        conn.close()
        return None

    # Flip status: if 0 -> 1, if 1 -> 0
    new_status = 1 if row["done"] == 0 else 0

    cursor.execute(
        "UPDATE tasks SET done = ? WHERE id = ?",
        (new_status, task_id)
    )
    conn.commit()
    conn.close()

    return {
        "id": row["id"],
        "title": row["title"],
        "done": new_status,
        "created_at": row["created_at"]
    }


def delete_task(task_id):
    """
    Delete a task from the database by its ID using a parameterized query (?).
    Returns True if a row was deleted, False if the ID was not found.
    """
    conn = get_db_connection()
    cursor = conn.cursor()

    cursor.execute("DELETE FROM tasks WHERE id = ?", (task_id,))
    deleted = cursor.rowcount > 0

    conn.commit()
    conn.close()
    return deleted

2. app.py: the Flask API

app.py
What it does

Serves the web page and offers 4 API routes that the page calls.

How to run
cd day6 pip install -r requirements.txt python app.py # then open http://127.0.0.1:5000
The logic, step by step
  1. database.init_db() runs once at start-up, so the table always exists.
  2. The POST route reads JSON with request.get_json(silent=True) or {} (so bad JSON doesn't crash it), checks that title is text, strips spaces, and checks the length.
  3. Each route returns jsonify(data), status_code. The status code tells the browser whether it worked.

from flask import Flask, render_template, request, jsonify
import database

# Initialize the Flask web application
app = Flask(__name__)

# Automatically create the database file and table if they do not exist
database.init_db()


@app.route("/")
def home():
    """
    Renders and serves the single-page HTML frontend.
    """
    return render_template("index.html")


@app.route("/api/tasks", methods=["GET"])
def get_tasks():
    """
    GET /api/tasks
    Fetches all tasks from the database (newest first) and returns them as JSON.
    """
    tasks = database.get_all_tasks()
    return jsonify(tasks), 200


@app.route("/api/tasks", methods=["POST"])
def create_task():
    """
    POST /api/tasks
    Expects a JSON body: { "title": "Study Python" }
    Validates input:
      - Title cannot be empty or just whitespace.
      - Title must be under 200 characters.
    Returns the newly created task on success, or an error message with status 400.
    """
    data = request.get_json(silent=True) or {}
    title = data.get("title", "")

    # Input validation: check for string type, strip whitespace
    if not isinstance(title, str):
        return jsonify({"error": "Task title must be text."}), 400

    clean_title = title.strip()

    # Rule: title must not be empty
    if not clean_title:
        return jsonify({"error": "Task title cannot be empty."}), 400

    # Rule: title must be under 200 characters
    if len(clean_title) > 200:
        return jsonify({"error": "Task title must be under 200 characters."}), 400

    # Save to the database using parameterized query
    new_task = database.add_task(clean_title)
    return jsonify(new_task), 201


@app.route("/api/tasks/<int:task_id>", methods=["PATCH"])
def toggle_task(task_id):
    """
    PATCH /api/tasks/<id>
    Toggles a task between done (1) and not done (0).
    Returns the updated task, or 404 if the task ID was not found.
    """
    updated_task = database.toggle_task(task_id)
    if updated_task is None:
        return jsonify({"error": f"Task with ID {task_id} not found."}), 404

    return jsonify(updated_task), 200


@app.route("/api/tasks/<int:task_id>", methods=["DELETE"])
def remove_task(task_id):
    """
    DELETE /api/tasks/<id>
    Deletes a task by ID.
    Returns a success message, or 404 if the task ID was not found.
    """
    deleted = database.delete_task(task_id)
    if not deleted:
        return jsonify({"error": f"Task with ID {task_id} not found."}), 404

    return jsonify({"message": "Task deleted successfully."}), 200


if __name__ == "__main__":
    # Run the server locally on port 5000
    app.run(debug=True, port=5000)

3. static/app.js: the page logic

static/app.js
What it does

Draws the task list and calls the API when you add, tick or delete a task.

The logic, step by step
  1. loadTasks() runs fetch('/api/tasks') and passes the list to renderTaskList(tasks), which builds one list item per task, each with a checkbox and a delete button.
  2. Submitting the form POSTs {title}. If the server answers with an error, showError(message) shows the server's message.
  3. The checkbox calls toggleTask(id) (PATCH) and the button calls deleteTask(id) (DELETE). After each one, the list is loaded again.

// ======================================================
// STUDENT TASK TRACKER - FRONTEND JAVASCRIPT
// Uses vanilla JavaScript and the standard fetch() API
// to communicate with the Flask backend.
// ======================================================

// Grab references to key HTML DOM elements
const taskForm = document.getElementById("taskForm");
const taskTitleInput = document.getElementById("taskTitleInput");
const charCounter = document.getElementById("charCounter");
const errorBanner = document.getElementById("errorBanner");
const taskList = document.getElementById("taskList");
const emptyState = document.getElementById("emptyState");
const taskStats = document.getElementById("taskStats");

// Run loadTasks as soon as the HTML document is fully loaded
document.addEventListener("DOMContentLoaded", () => {
    loadTasks();
});

// Update the character counter while the user types (max 200 characters)
taskTitleInput.addEventListener("input", () => {
    const length = taskTitleInput.value.length;
    charCounter.textContent = `${length}/200`;
    if (length > 0) {
        clearError();
    }
});

// Helper function to show error messages on the page
function showError(message) {
    errorBanner.textContent = message;
    errorBanner.style.display = "block";
}

// Helper function to hide the error message banner
function clearError() {
    errorBanner.textContent = "";
    errorBanner.style.display = "none";
}

// ======================================================
// FEATURE 2: See all tasks in a list, newest first
// ======================================================
async function loadTasks() {
    try {
        const response = await fetch("/api/tasks");
        if (!response.ok) {
            throw new Error("Failed to load tasks from server.");
        }

        const tasks = await response.json();
        renderTaskList(tasks);
    } catch (err) {
        showError("Could not connect to the server. Please check if Flask is running.");
    }
}

// Renders the list of tasks inside the <ul> element
function renderTaskList(tasks) {
    taskList.innerHTML = ""; // Clear current list

    // Toggle empty state message
    if (tasks.length === 0) {
        emptyState.style.display = "block";
        taskStats.textContent = "0 tasks";
        return;
    }

    emptyState.style.display = "none";

    // Count how many tasks are completed
    const completedCount = tasks.filter(t => t.done === 1).length;
    taskStats.textContent = `${completedCount} of ${tasks.length} done`;

    // Loop through tasks and build HTML for each task item
    tasks.forEach(task => {
        const li = document.createElement("li");
        li.className = `task-item ${task.done === 1 ? "is-done" : ""}`;
        li.setAttribute("data-id", task.id);

        // Task content: checkbox and title
        const taskContent = document.createElement("div");
        taskContent.className = "task-content";

        // Checkbox (Feature 3: Mark done or not done)
        const checkbox = document.createElement("input");
        checkbox.type = "checkbox";
        checkbox.className = "task-checkbox";
        checkbox.checked = task.done === 1;
        checkbox.setAttribute("aria-label", `Mark "${task.title}" as complete`);
        checkbox.addEventListener("change", () => toggleTask(task.id));

        // Details container (title and timestamp)
        const details = document.createElement("div");
        details.className = "task-details";

        const titleSpan = document.createElement("span");
        titleSpan.className = "task-title";
        titleSpan.textContent = task.title; // Using textContent prevents XSS attacks

        const timeSpan = document.createElement("span");
        timeSpan.className = "task-time";
        timeSpan.textContent = `Added: ${task.created_at}`;

        details.appendChild(titleSpan);
        details.appendChild(timeSpan);

        taskContent.appendChild(checkbox);
        taskContent.appendChild(details);

        // Delete button (Feature 4: Delete a task)
        const deleteBtn = document.createElement("button");
        deleteBtn.className = "btn-delete";
        deleteBtn.textContent = "Delete";
        deleteBtn.setAttribute("aria-label", `Delete task "${task.title}"`);
        deleteBtn.addEventListener("click", () => deleteTask(task.id));

        li.appendChild(taskContent);
        li.appendChild(deleteBtn);

        taskList.appendChild(li);
    });
}

// ======================================================
// FEATURE 1: Add a task
// ======================================================
taskForm.addEventListener("submit", async (e) => {
    e.preventDefault(); // Prevent standard page reload

    const title = taskTitleInput.value.trim();

    // Frontend validation: check not empty
    if (!title) {
        showError("Task title cannot be empty. Please enter a task.");
        taskTitleInput.focus();
        return;
    }

    // Frontend validation: check length under 200 characters
    if (title.length > 200) {
        showError("Task title must be under 200 characters.");
        return;
    }

    clearError();

    try {
        const response = await fetch("/api/tasks", {
            method: "POST",
            headers: {
                "Content-Type": "application/json"
            },
            body: JSON.stringify({ title: title })
        });

        const result = await response.json();

        if (!response.ok) {
            // Show validation or server error message returned by backend
            showError(result.error || "Failed to add task.");
            return;
        }

        // Reset input field and character counter on success
        taskTitleInput.value = "";
        charCounter.textContent = "0/200";

        // Refresh task list to show the new task at the top
        loadTasks();
    } catch (err) {
        showError("Network error while trying to add task.");
    }
});

// ======================================================
// FEATURE 3: Mark a task as done or not done with checkbox
// ======================================================
async function toggleTask(taskId) {
    try {
        const response = await fetch(`/api/tasks/${taskId}`, {
            method: "PATCH"
        });

        if (!response.ok) {
            const result = await response.json();
            showError(result.error || "Failed to update task.");
            return;
        }

        // Refresh list to update strikethrough styling and completed counter
        loadTasks();
    } catch (err) {
        showError("Network error while updating task.");
    }
}

// ======================================================
// FEATURE 4: Delete a task with a "Delete" button
// ======================================================
async function deleteTask(taskId) {
    try {
        const response = await fetch(`/api/tasks/${taskId}`, {
            method: "DELETE"
        });

        if (!response.ok) {
            const result = await response.json();
            showError(result.error || "Failed to delete task.");
            return;
        }

        // Refresh list to remove the deleted task
        loadTasks();
    } catch (err) {
        showError("Network error while deleting task.");
    }
}
