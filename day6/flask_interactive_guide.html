What is Flask?

Flask is a small Python library for building websites and web APIs. You write normal Python functions, and Flask connects each one to a web address (URL). When someone visits that address, your function runs and its answer goes back to their browser.

🐍 Written in Python 🪶 "Micro" framework: small core, add only what you need ⚡ A working app in 5 lines 🏢 Used by Netflix, Reddit, LinkedIn and many others

HTML pages

Templates: HTML with blanks to fill in

Returning one line of text is fine, but real pages need HTML. Flask uses Jinja templates: HTML files with placeholders. Your Python sends data in, and Jinja fills the blanks. Edit the template or the data below and watch the page update live.

📄 templates/index.html
🐍 Data from Python (JSON)
🌐 What the browser shows
Syntax:
{{ x }} prints a value.
{% for … %} / {% if … %} add logic.
{{ x|upper }} applies a filter.
🔒 Jinja escapes values automatically. Try setting a name to <b>hi</b>: it shows as text and is never run as HTML.
The language of the web

HTTP methods and status codes

Every request has a method (what you want to do) and every response has a status code (how it went). In Flask you choose methods with methods=["POST"] in @app.route.

Status codes: click one

Status codes are 3-digit numbers. The first digit tells you the kind: 2xx success, 3xx redirect, 4xx your mistake, 5xx server's mistake.
