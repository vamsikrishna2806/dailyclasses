DAY 21 · ARCHITECTURE

The MCP + LangGraph agent

Four views of the same system: the components, the graph, what happens at startup, and what happens on every question. For the animated walkthrough, open index.html.

1 · Component view

One host process (agent_graph.py) contains the LLM, the LangGraph graph and one MCP client per server. Each server wraps a real system.

2 · LangGraph view (the ReAct loop)

tools_condition looks at the last AI message. If it contains tool_calls, the graph goes to tools; otherwise it goes to END. ToolNode runs each call, and each one is an MCP tools/call.

3 · Startup: discovery

Before the first question, the host connects to every server and asks what it offers. The LLM only knows tools that were discovered here.

4 · One question, end to end

"What's the weather in Hyderabad?" Notice that the LLM never talks to an MCP server. It only returns a tool_call, and the host does the rest.
