Day 21: MCP servers and an MCP agent

MCP (Model Context Protocol) is a standard way to give an AI tools. A server offers the tools, and a client connects to it, lists the tools and calls them. Here you build both sides.

The servers (they offer tools)

1. servers/math_server.py: your first MCP server

servers/math_server.py
What it does

Offers maths tools (add, multiply, div, power), a resource (constants) and a prompt template, over stdio.

How to run
npx @modelcontextprotocol/inspector .venv\Scripts\python.exe servers/math_server.py
The logic, step by step
  1. mcp = FastMCP("Math") creates the server. "Math" is the name clients see.
  2. @mcp.tool() on a normal function turns it into a tool. The type hints become the input schema, and the docstring becomes the description the AI reads.
  3. @mcp.resource("math://constants") is read-only data that a client can fetch by its address.
  4. @mcp.prompt() is a reusable prompt template ("solve step by step").
  5. mcp.run(transport="stdio"): the client starts this file as a child process and they exchange JSON-RPC messages over stdin/stdout.
Watch out: Never use print() in a stdio server. stdout is the message channel, so a print garbles the protocol. Log to stderr instead.
Show the full source of servers/math_server.py (46 lines)
"""
math_server.py  -  Your FIRST MCP server (stdio transport)
Try it:  mcp dev servers/math_server.py     (opens the MCP Inspector)
"""
from mcp.server.fastmcp import FastMCP

mcp = FastMCP("Math")              # the name clients will see


@mcp.tool()
def add(a: float, b: float) -> float:
    """Add two numbers and return the sum."""
    return a + b


@mcp.tool()
def multiply(a: float, b: float) -> float:
    """Multiply two numbers and return the product."""
    return a * b


@mcp.tool()
def div(a: float, b: float) -> float:
    """div of two numbers"""
    return a / b

@mcp.tool()
def power(base: float, exponent: float) -> float:
    """Raise base to the power of exponent."""
    return base ** exponent

@mcp.resource("math://constants")
def constants() -> str:
    """Useful math constants (read-only data)."""
    return "pi = 3.14159\ne = 2.71828\ngolden_ratio = 1.61803"


@mcp.prompt()
def explain_step_by_step(problem: str) -> str:
    """Template: solve a math problem step by step."""
    return f"Solve step by step. Use the math tools for EVERY calculation:\n{problem}"


if __name__ == "__main__":
    # stdio: talk JSON-RPC over stdin/stdout. NEVER print() in a stdio server!
    mcp.run(transport="stdio")

2. servers/weather_server.py: wrapping a real API

servers/weather_server.py
What it does

Live weather as MCP tools: get_current_weather(city) and get_forecast(city, days), built on the free Open-Meteo API.

The logic, step by step
  1. _locate() geocodes the city name to latitude and longitude (raising an error if it isn't found).
  2. get_current_weather asks for the current temperature, humidity, wind and weather code, and maps the code to words using CODES.
  3. get_forecast limits days to 1-7 and returns one dictionary per day (min, max, rain chance).
  4. The tools are async and use httpx.AsyncClient, so the server doesn't freeze while it waits.
Key idea: This is the most common real-world MCP pattern: LLM → MCP tool → your server → an existing REST API.
Show the full source of servers/weather_server.py (69 lines)
"""
weather_server.py  -  REAL-TIME data: wraps the free Open-Meteo REST API as MCP tools.
No API key needed.  Try it:  mcp dev servers/weather_server.py

This is the most common real-world MCP pattern:
    LLM  ->  MCP tool  ->  your server  ->  existing REST API  ->  live data
"""
import logging

import httpx
from mcp.server.fastmcp import FastMCP

logging.getLogger("httpx").setLevel(logging.WARNING)   # keep the console quiet

mcp = FastMCP("Weather")

GEO_URL = "https://geocoding-api.open-meteo.com/v1/search"
WX_URL = "https://api.open-meteo.com/v1/forecast"
CODES = {0: "clear sky", 1: "mainly clear", 2: "partly cloudy", 3: "overcast", 45: "fog", 48: "fog",
         51: "light drizzle", 53: "drizzle", 55: "heavy drizzle", 61: "light rain", 63: "rain",
         65: "heavy rain", 71: "light snow", 73: "snow", 75: "heavy snow", 80: "rain showers",
         81: "rain showers", 82: "violent rain showers", 95: "thunderstorm", 96: "thunderstorm with hail",
         99: "thunderstorm with hail"}


async def _locate(client: httpx.AsyncClient, city: str) -> dict:
    r = await client.get(GEO_URL, params={"name": city, "count": 1})
    r.raise_for_status()
    hits = r.json().get("results")
    if not hits:
        raise ValueError(f"City '{city}' not found")
    return hits[0]


@mcp.tool()
async def get_current_weather(city: str) -> dict:
    """Get the LIVE current weather for a city (temperature in Celsius, wind, conditions)."""
    async with httpx.AsyncClient(timeout=15) as client:
        place = await _locate(client, city)
        r = await client.get(WX_URL, params={
            "latitude": place["latitude"], "longitude": place["longitude"],
            "current": "temperature_2m,relative_humidity_2m,wind_speed_10m,weather_code",
            "timezone": "auto"})
        r.raise_for_status()
        cur = r.json()["current"]
    return {"city": place["name"], "country": place.get("country"), "time": cur["time"],
            "temperature_c": cur["temperature_2m"], "humidity_pct": cur["relative_humidity_2m"],
            "wind_kmh": cur["wind_speed_10m"], "conditions": CODES.get(cur["weather_code"], "unknown")}


@mcp.tool()
async def get_forecast(city: str, days: int = 3) -> list[dict]:
    """Get a daily forecast (min/max Celsius, rain chance) for the next 1-7 days."""
    days = max(1, min(days, 7))
    async with httpx.AsyncClient(timeout=15) as client:
        place = await _locate(client, city)
        r = await client.get(WX_URL, params={
            "latitude": place["latitude"], "longitude": place["longitude"], "forecast_days": days,
            "daily": "temperature_2m_min,temperature_2m_max,precipitation_probability_max,weather_code",
            "timezone": "auto"})
        r.raise_for_status()
        d = r.json()["daily"]
    return [{"date": d["time"][i], "min_c": d["temperature_2m_min"][i], "max_c": d["temperature_2m_max"][i],
             "rain_chance_pct": d["precipitation_probability_max"][i],
             "conditions": CODES.get(d["weather_code"][i], "unknown")} for i in range(len(d["time"]))]


if __name__ == "__main__":
    mcp.run(transport="stdio")

3. servers/notes_server.py: an HTTP server

servers/notes_server.py
What it does

A notes service (add, list, search) that runs as a small web server instead of a child process.

How to run
python servers/notes_server.py # http://127.0.0.1:8000/mcp
The logic, step by step
  1. NOTES is a list in memory, and each note gets an id and a creation time.
  2. search_notes does a case-insensitive match on the title or body.
  3. mcp.run(transport="streamable-http") serves MCP at /mcp. It must be started before any client connects.
  4. With HTTP, print() is fine, because stdout isn't the protocol channel.
Show the full source of servers/notes_server.py (44 lines)
"""
notes_server.py  -  An MCP server over Streamable HTTP (a tiny web service)
Run:  python servers/notes_server.py      ->  http://127.0.0.1:8000/mcp
"""
from datetime import datetime

from mcp.server.fastmcp import FastMCP

mcp = FastMCP("Notes", host="127.0.0.1", port=8000)
NOTES: list[dict] = []          # in-memory "database"


@mcp.tool()
def add_note(title: str, body: str) -> str:
    """Save a note with a title and a body. Returns a confirmation."""
    note = {"id": len(NOTES) + 1, "title": title, "body": body,
            "created": datetime.now().isoformat(timespec="seconds")}
    NOTES.append(note)
    return f"Saved note #{note['id']}: {title}"


@mcp.tool()
def list_notes() -> list[dict]:
    """Return every saved note."""
    return NOTES


@mcp.tool()
def search_notes(keyword: str) -> list[dict]:
    """Find notes whose title or body contains the keyword (case-insensitive)."""
    k = keyword.lower()
    return [n for n in NOTES if k in n["title"].lower() or k in n["body"].lower()]


@mcp.resource("notes://all")
def all_notes() -> str:
    """All notes as plain text."""
    return "\n".join(f"#{n['id']} {n['title']}: {n['body']}" for n in NOTES) or "(no notes yet)"


if __name__ == "__main__":
    # HTTP transport: printing is fine here (stdout is not the protocol channel)
    print("Notes MCP server -> http://127.0.0.1:8000/mcp")
    mcp.run(transport="streamable-http")

4. raw_client.py: MCP with no AI

raw_client.py
What it does

Connects to the math server and runs every MCP action by hand: initialize, list tools, call a tool, read a resource, get a prompt.

How to run
python raw_client.py
The logic, step by step
  1. StdioServerParameters(command=python, args=[math_server.py]) describes how to start the server.
  2. stdio_client(SERVER) starts it as a child process and gives back the read and write streams. ClientSession speaks MCP over them.
  3. session.initialize() is the handshake (protocol version, capabilities).
  4. list_tools() lists the tools. call_tool("multiply", {"a": 6, "b": 7}) returns 42.0.
  5. read_resource("math://constants") and get_prompt(...) show the two other kinds of MCP features.
Show the full source of raw_client.py (36 lines)
"""
raw_client.py  -  Talk to an MCP server directly, no LLM involved.
Run:  python raw_client.py
"""
import asyncio
import sys
from pathlib import Path

from mcp import ClientSession, StdioServerParameters
from mcp.client.stdio import stdio_client
SERVER = StdioServerParameters(command=sys.executable, args=[str(Path(__file__).parent / "servers" / "math_server.py")])


async def main():
    async with stdio_client(SERVER) as (read, write):
        async with ClientSession(read, write) as session:
            init = await session.initialize()
            print(f"Connected to '{init.serverInfo.name}' (protocol {init.protocolVersion})")

            tools = await session.list_tools()
            for t in tools.tools:
                print(f"  tool: {t.name:10} - {t.description}")

            result = await session.call_tool("multiply", {"a": 6, "b": 7})
            print("multiply(6, 7) =", result.content[0].text)

            res = await session.read_resource("math://constants")
            print("resource math://constants ->", res.contents[0].text.replace("\n", " | "))

            prompt = await session.get_prompt("explain_step_by_step", {"problem": "2^10 + 5"})
            print("prompt ->", prompt.messages[0].content.text)
            print("Done. (that is exactly what LangGraph's adapter does for you)")


if __name__ == "__main__":
    asyncio.run(main())

5. agent/agent_graph.py: a LangGraph agent with 6 MCP servers

agent/agent_graph.py
What it does

A chat agent (Ollama llama3.2) whose tools come from 6 MCP servers: math, weather and notes (yours), fetch and time (official), and DeepWiki (public, online).

How to run
python agent/agent_graph.py
The logic, step by step
  1. SERVERS lists each server and how to reach it: stdio with a command, or streamable_http with a URL.
  2. load_mcp_tools() uses MultiServerMCPClient and asks each server for its tools. A server that is missing or offline is skipped with [skip], so the agent still works.
  3. ChatOllama(...).bind_tools(tools) tells the model about every MCP tool.
  4. The graph: the agent node calls the LLM with the SYSTEM prompt (which says which tool to use for what). tools_condition sends the flow to ToolNode when the reply has tool calls, and to END otherwise.
  5. ToolNode runs the MCP tools/call for each request. The edge tools → agent loops back so the model can read the results.
  6. MemorySaver plus thread_id remembers the conversation between questions.
  7. astream(..., stream_mode="updates") prints every tool call and result as it happens.
Flow
START → agent (LLM) ── tool_calls? ──yes──▶ tools (MCP tools/call) ──▶ agent …
                       └──no──▶ END
Show the full source of agent/agent_graph.py (114 lines)
"""
agent_graph.py  -  A LangGraph ReAct agent whose tools come from MCP servers.

    START -> agent (LLM) --tool_calls?--> tools (MCP) -> agent ... -> END

MCP servers used (each one is optional - missing ones are skipped):
  math   : our own stdio server                (servers/math_server.py)
  weather: our own LIVE weather server         (servers/weather_server.py -> Open-Meteo API)
  notes  : our own HTTP server                 (run servers/notes_server.py first)
  fetch  : OFFICIAL real-time web fetcher      (pip install mcp-server-fetch)
  time   : OFFICIAL current time / time zones  (pip install mcp-server-time)
  deepwiki: PUBLIC remote server for GitHub repo docs (internet, no key)
"""
import asyncio
import sys
from pathlib import Path
from typing import Annotated, TypedDict

from langchain_core.messages import AnyMessage, HumanMessage, SystemMessage
from langchain_mcp_adapters.client import MultiServerMCPClient
from langchain_ollama import ChatOllama
from langgraph.checkpoint.memory import MemorySaver
from langgraph.graph import END, START, StateGraph
from langgraph.graph.message import add_messages
from langgraph.prebuilt import ToolNode, tools_condition

ROOT = Path(__file__).resolve().parent.parent
PY = sys.executable
OLLAMA_MODEL = "llama3.2"     # must support tool calling: llama3.2, llama3.1, qwen2.5:7b (smarter), mistral-nemo

# 1) Which MCP servers to connect to ------------------------------------------
SERVERS = {
    "math":     {"transport": "stdio", "command": PY, "args": [str(ROOT / "servers" / "math_server.py")]},
    "weather":  {"transport": "stdio", "command": PY, "args": [str(ROOT / "servers" / "weather_server.py")]},
    "notes":    {"transport": "streamable_http", "url": "http://127.0.0.1:8000/mcp"},
    "fetch":    {"transport": "stdio", "command": PY, "args": ["-m", "mcp_server_fetch"]},
    "time":     {"transport": "stdio", "command": PY, "args": ["-m", "mcp_server_time"]},
    "deepwiki": {"transport": "streamable_http", "url": "https://mcp.deepwiki.com/mcp"},
}

SYSTEM = """You are a helpful assistant connected to MCP tools.
- For ANY arithmetic, use the math tools (never calculate in your head).
- For the CURRENT time in a city, call get_current_time with an IANA timezone (e.g. "Asia/Tokyo").
  Use convert_time only when the user gives a specific time to convert.
- For live weather use get_current_weather / get_forecast.
- To read a web page (docs, Wikipedia, news) use the fetch tool.
- For questions about a GitHub repository use the deepwiki tools (repoName like "langchain-ai/langgraph").
- Use the notes tools to save or look up notes.
Answer briefly and say which tool gave you the data."""


# 2) Graph state: just a list of chat messages ---------------------------------
class State(TypedDict):
    messages: Annotated[list[AnyMessage], add_messages]


async def load_mcp_tools():
    """Connect to every server; skip the ones that are not available."""
    client = MultiServerMCPClient(SERVERS)
    tools = []
    for name in SERVERS:
        try:
            server_tools = await client.get_tools(server_name=name)
            tools += server_tools
            print(f"  [ok]   {name:9} -> {', '.join(t.name for t in server_tools)}")
        except Exception as e:  # server not installed / not running / offline
            print(f"  [skip] {name:9} -> {type(e).__name__}")
    return tools


async def build_graph():
    tools = await load_mcp_tools()
    llm = ChatOllama(model=OLLAMA_MODEL, temperature=0).bind_tools(tools)

    async def agent(state: State):
        reply = await llm.ainvoke([SystemMessage(SYSTEM)] + state["messages"])
        return {"messages": [reply]}

    g = StateGraph(State)
    g.add_node("agent", agent)
    g.add_node("tools", ToolNode(tools))         # runs MCP tools/call for us
    g.add_edge(START, "agent")
    g.add_conditional_edges("agent", tools_condition)   # tool_calls? -> "tools" else END
    g.add_edge("tools", "agent")
    return g.compile(checkpointer=MemorySaver())  # memory across turns


async def main():
    print("Connecting to MCP servers...")
    graph = await build_graph()
    config = {"configurable": {"thread_id": "day21"}}
    print("\nAsk me anything (live weather, time, math, web pages, GitHub repos, notes). 'quit' to exit.")

    while True:
        q = input("\nYou: ").strip()
        if q.lower() in {"quit", "exit", "q"}:
            break
        if not q:
            continue
        async for update in graph.astream({"messages": [HumanMessage(q)]}, config, stream_mode="updates"):
            for node, data in update.items():
                msg = data["messages"][-1]
                if node == "agent" and getattr(msg, "tool_calls", None):
                    for tc in msg.tool_calls:
                        print(f"  -> [agent] calls {tc['name']}({tc['args']})")
                elif node == "tools":
                    for m in data["messages"]:
                        print(f"  <- [tool:{m.name}] {str(m.content)[:160]}")
                else:
                    print(f"\nAgent: {msg.content}")


if __name__ == "__main__":
    asyncio.run(main())

6. agent/agent_prebuilt.py: the same idea in about 25 lines

agent/agent_prebuilt.py
What it does

Asks one fixed question (Tokyo time plus Hyderabad weather) using a prebuilt ReAct agent.

How to run
python agent/agent_prebuilt.py
The logic, step by step
  1. MultiServerMCPClient({...}) connects to 4 servers, and get_tools() turns their MCP tools into LangChain tools.
  2. create_agent (or the older create_react_agent, chosen by the try/except import) builds the whole tool loop for you.
  3. agent.ainvoke(...) runs it, and the program prints the last message.
Show the full source of agent/agent_prebuilt.py (42 lines)
"""
agent_prebuilt.py  -  Same agent in ~25 lines using a prebuilt ReAct agent.
"""
import asyncio
import sys
from pathlib import Path

from langchain_mcp_adapters.client import MultiServerMCPClient
from langchain_ollama import ChatOllama

try:                                    # LangChain >= 1.0
    from langchain.agents import create_agent

    def make_agent(llm, tools, prompt):
        return create_agent(llm, tools, system_prompt=prompt)
except ImportError:                     # older LangGraph
    from langgraph.prebuilt import create_react_agent

    def make_agent(llm, tools, prompt):
        return create_react_agent(llm, tools, prompt=prompt)

ROOT = Path(__file__).resolve().parent.parent


async def main():
    client = MultiServerMCPClient({
        "weather":  {"transport": "stdio", "command": sys.executable, "args": [str(ROOT / "servers" / "weather_server.py")]},
        "time":     {"transport": "stdio", "command": sys.executable, "args": ["-m", "mcp_server_time"]},
        "fetch":    {"transport": "stdio", "command": sys.executable, "args": ["-m", "mcp_server_fetch"]},
        "deepwiki": {"transport": "streamable_http", "url": "https://mcp.deepwiki.com/mcp"},
    })
    tools = await client.get_tools()                 # MCP tools -> LangChain tools
    agent = make_agent(ChatOllama(model="llama3.2", temperature=0), tools,
                       "Always use tools for live data (time, weather, web pages, GitHub repos).")

    question = "What time is it in Tokyo right now, and what's the weather in Hyderabad?"
    result = await agent.ainvoke({"messages": [{"role": "user", "content": question}]})
    print(result["messages"][-1].content)


if __name__ == "__main__":
    asyncio.run(main())
