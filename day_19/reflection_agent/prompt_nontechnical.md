# Reflection Agent — Plain English Guide

## What does this agent do?

This agent writes something for you, then **reads its own work like a strict editor** and improves it — just like a student who writes an essay, gets feedback from a teacher, and rewrites it.

## How to talk to it

Ask it to write anything short:

- "Write a short email asking my boss for Friday off"
- "Write a product description for a reusable water bottle"
- "Explain what an API is to a 10-year-old"

## How it works (simple version)

1. **Write** — the agent makes a first draft
2. **Critique** — it acts as an editor: either says "APPROVED" or lists 2–3 fixes
3. **Revise** — it rewrites the draft using those fixes
4. Steps 2 and 3 repeat until the editor approves (at most 3 times)

## What you get back

- The final, improved text
- A short log of each step so you can see the improvement happen

## Example conversation

> **You:** Write a short email asking my boss for Friday off
>
> *✍️ writer: first draft (81 words)*
> *🧐 critic: APPROVED*
>
> **Agent:** Dear [Boss's Name], I am writing to request this Friday off...

## Good to know

- One AI plays all three roles: writer, editor and reviser
- Free, runs on your own computer, no account needed
- The 3-round limit stops it from editing forever

## Limitations

- Best for short pieces of writing
- The "editor" is the same AI, so it can miss some mistakes
- Sometimes the first draft is already approved, so you will not see any revision
