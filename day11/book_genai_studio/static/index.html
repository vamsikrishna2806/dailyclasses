What happens when you upload?
  1. Extract – text is read from each page (PDF), chapter (EPUB) or paragraph (DOCX).
  2. Clean – broken words and extra spaces are fixed.
  3. Find chapters – headings like “Chapter 3” or “Part Two” are detected.
  4. Chunk – text is cut into ~450-token passages with a little overlap.
  5. Index – keyword search always; with an API key, embeddings for meaning search too.
