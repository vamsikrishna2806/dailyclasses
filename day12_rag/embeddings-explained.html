What are Embeddings?

An embedding turns a word or a sentence into a list of numbers that captures its meaning.

1Computers only understand numbers

Computers can't read words. So first, let's try the simple way: turn every letter into its number code.

😕 "dog" and "puppy" mean almost the same thing… but their numbers are completely different!
Letter codes only capture spelling, not meaning.
⭐ We need numbers that describe what a word means, so similar words get similar numbers. That's exactly what an embedding is.

2Describe each word with scores

Like a player card in a video game (speed, power, skill…), we give every word a score from 0 to 1 on some features. Click a word:

🎮 Analogy: a cricket player card has Batting 0.9, Bowling 0.2, Fielding 0.7. Those 3 numbers describe the player. An embedding is the same idea for words.
⭐ That list of numbers is the embedding (also called a vector). Each number is one dimension.

5Sentences get embeddings too

A whole sentence can also become one list of numbers. Then we can find sentences with the same meaning, even with different words. Type or pick a search:

🔎 Search "kitten" — it finds the cat sentence even though the word "kitten" isn't in it. Normal keyword search (Ctrl+F) would find nothing! (This demo knows about 30 words.)

6Magic: math with meanings

Because meaning is stored as numbers, we can add and subtract meanings. The famous example:

👑 king − 👨 man + 👩 woman ≈ 👸 queen
Axes: → Royalty, ↑ Female. "king − man" removes the "male" part and keeps "royal". Adding "woman" adds "female" → lands on queen.

"dog" → [0.021, -0.134, 0.078, 0.311, -0.045, 0.196, … 384 numbers]
# pip install sentence-transformers
from sentence_transformers import SentenceTransformer, util

model = SentenceTransformer("all-MiniLM-L6-v2")      # free, runs locally

a = model.encode("I love my puppy")
b = model.encode("Dogs are great pets")
c = model.encode("The stock market fell")

print(len(a))                  # 384  ← numbers per sentence
print(util.cos_sim(a, b))      # ~0.6  similar meaning
print(util.cos_sim(a, c))      # ~0.0  unrelated
