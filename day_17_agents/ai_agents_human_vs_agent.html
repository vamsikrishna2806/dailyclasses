Part 2

An LLM alone is a brain in a jar

This is the main idea on the page. ChatGPT, Claude or Llama on their own can only talk. Give the brain a body (tools, memory and a loop) and it can do things. That is an agent.

🫙 LLM / Chatbot

  • Knows only what it saw during training (old data)
  • Can't check today's weather, send an email or run code
  • Forgets everything once the chat ends
  • Answers once and doesn't check its own work

🤖 AI Agent

  • Tools: search, code, APIs, databases, email
  • Memory: remembers past chats and facts about you
  • Loop: think → act → look at the result → repeat
  • Goal-driven: keeps going until the task is done

Part 4

Memory: whiteboard vs diary

You have two kinds of memory: what you're thinking about right now, and things stored for years. Agents have the same two. Watch new messages push old ones out of the context window. Only messages marked ⭐ important get saved to long-term memory.

⚡ Short-term memory = Context window

🧑 Like holding a phone number in your head while you dial it.
🤖 The chat messages sent to the LLM on every call. It has a size limit (tokens), so old messages fall out.

🗑️ Forgotten: 0 messages

📚 Long-term memory = Vector database

🧑 Like your diary, or remembering your best friend's birthday.
🤖 Facts saved as embeddings in a vector DB (Chroma, FAISS, Pinecone). When needed, the agent searches by meaning and puts the results back into its context. This is RAG.

Engineer's note: the LLM itself is stateless. It remembers nothing between calls. Every bit of "memory" is your code putting the right text back into the prompt each time.

Part 6

What the agent loop looks like in code

Simplified Python. Frameworks like LangChain or LangGraph hide this, but underneath they all do roughly this. The comments link each line back to the human.

# 🧑 job description / values system_prompt = "You are a helpful weather assistant. Be honest." # 🧑 hands → 🤖 tools tools = { "get_weather": get_weather, "search_web": search_web } # 🧑 short-term memory → 🤖 context window messages = [system_prompt, user_question] # 👀 PERCEIVE while True: # 🔁 the loop (nervous system) reply = llm(messages, tools=tools) # 🧠 THINK (brain = LLM) if reply.tool_call: # LLM decided: "I need a tool" result = tools[reply.tool_call.name](**reply.tool_call.args) # 🛠️ ACT messages.append(result) # 🔎 OBSERVE → back into memory continue # go round again vector_db.save(important_facts(messages)) # 💾 long-term memory return reply.text # 👄 SPEAK final answer

💡 Key point: the LLM never runs the tool itself. It only says which tool to call and with what inputs. Your code runs the tool and gives the result back. The brain decides, the hands do the work.
