Weather Prediction Agent

weather_agent/main.py · Predicts tomorrow's max temperature from 7-day history

LangChain create_agent Ollama llama3.2 Open-Meteo API 2 tools CLI streaming
System Prompt Runtime instruction given to the LLM inside main.py
You are a weather analyst. To predict tomorrow's max temperature: 1. Call get_past_temperatures for the city. 2. Call temperature_trend for the same city. 3. Answer with: the predicted max temperature for tomorrow (one number in °C), and one or two short sentences explaining why, based on the data. Never invent temperatures. Only use numbers that came from the tools.

# ── GOAL ────────────────────────────────────────────────────────── Build a CLI weather prediction agent in Python using LangChain and LangGraph that predicts tomorrow's max temperature from 7-day historical data. # ── STACK ───────────────────────────────────────────────────────── LLM : Ollama llama3.2, temperature=0 (via langchain-ollama) Framework : LangChain create_agent with LangGraph backend API : Open-Meteo (free, no API key) Geocoding : https://geocoding-api.open-meteo.com/v1/search Weather : https://api.open-meteo.com/v1/forecast # ── TOOLS (2) ───────────────────────────────────────────────────── get_past_temperatures(city: str) → str - Geocode city → lat/lon - Fetch past_days=7, forecast_days=1, daily max+min temps - Return: "City, Country:\nDATE: max X°C, min Y°C\n..." temperature_trend(city: str) → str - Fetch last 7 days of max temperatures (same API call) - Compute linear regression slope (°C per day) - Compute straight-line next value and 3-day moving average - Return: "trend: ±X.XX °C/day | next: Y.Y°C | avg3: Z.Z°C" # ── ENTRY POINT ─────────────────────────────────────────────────── File: main.py (single file — tools + agent together) - Accept city via sys.argv or interactive input(), default "Hyderabad" - Build question: "Predict tomorrow's maximum temperature in {city}." - Stream agent with stream_mode="values" - Print each step: 🧠 THINK→ACT (tool calls) | 🔎 OBSERVE | 🤖 Answer - After agent finishes, fetch Open-Meteo official forecast and print for comparison # ── FILES ───────────────────────────────────────────────────────── main.py ← tools + agent + main logic requirements.txt ← langchain, langchain-ollama, langgraph, requests .venv/
Tool Contracts Exact docstrings the LLM reads to decide when to call each tool
get_past_temperatures(city: str) → str """Get the real daily max and min temperatures (°C) for the last 7 days in a city, plus today. Use this first to see recent weather.""" temperature_trend(city: str) → str """Calculate the trend of the last 7 days of max temperatures in a city: how much it changes per day and the next value on the trend line. Use this to do the maths instead of guessing."""

Travel Assistant Agent

travel_agent/agent.py · Real-time destination weather + travel advice

LangGraph create_react_agent Ollama llama3.2 Open-Meteo API 1 tool Interactive CLI
System Prompt Runtime instruction from travel_agent/agent.py → SYSTEM_PROMPT
You are a friendly and knowledgeable travel assistant. When a user asks about a travel destination, use the get_destination_info tool to fetch real-time weather and conditions. Based on the data, give helpful, concise travel advice: • What to pack • Best activities • Anything relevant for the trip Always be encouraging and practical.

# ── GOAL ────────────────────────────────────────────────────────── Build a conversational travel assistant CLI agent in Python using LangChain and LangGraph with one real-time weather tool. # ── STACK ───────────────────────────────────────────────────────── LLM : Ollama llama3.2, temperature=0.3 (via langchain-ollama) Framework : LangGraph create_react_agent (prebuilt ReAct loop) API : Open-Meteo Geocoding + Weather (free, no API key) # ── TOOL (1) ────────────────────────────────────────────────────── get_destination_info(city: str) → str Step 1 — Geocode: GET geocoding-api.open-meteo.com/v1/search?name={city}&count=1 Extract lat, lon, country Step 2 — Weather: GET api.open-meteo.com/v1/forecast with: current = temperature_2m, apparent_temperature, relative_humidity_2m, wind_speed_10m, weathercode daily = temperature_2m_max, temperature_2m_min, precipitation_probability_max, weathercode forecast_days=3, timezone=auto Step 3 — Format: Map WMO weathercode → human label (dict of ~20 codes) Apply travel tip from temperature thresholds: <5°C → "Very cold — pack heavy winter clothing." <15 → "Cool weather — bring a jacket." ≤28 → "Pleasant weather — great for sightseeing!" ≤35 → "Warm — stay hydrated and use sunscreen." >35 → "Extremely hot — limit outdoor activities midday." Return multi-line string: header, current, 3-day table, tip # ── ENTRY POINT ─────────────────────────────────────────────────── Interactive while-loop CLI chat (agent.py): - Print header with model + tool name on startup - Exit on "quit" / "exit" / "q" / Ctrl+C - Wrap each turn: SystemMessage + HumanMessage → agent.invoke() - Print result["messages"][-1].content # ── FILES ───────────────────────────────────────────────────────── tools.py ← get_destination_info tool agent.py ← build_agent(), ask(), main() requirements.txt ← langchain, langchain-ollama, langgraph, requests .venv/

Political Scenario Agent

System Prompt Runtime instruction from political_scenario_agent/agent.py → SYSTEM_PROMPT
You are an expert political analyst and geopolitical strategist. Your role is to analyze political scenarios, current events, elections, policy decisions, international relations, and world affairs with clarity and balance. When analyzing a scenario: 1. Use the web_search tool to find current, factual information. 2. Present multiple perspectives without personal bias. 3. Explain the key players, their motivations, and likely outcomes. 4. Highlight risks, opportunities, and historical context where relevant. 5. Keep your analysis concise, structured, and evidence-based. Always cite your sources by mentioning where you found the information.

# ── GOAL ────────────────────────────────────────────────────────── Build a conversational political analysis CLI agent in Python using LangChain and LangGraph with real-time DuckDuckGo web search. # ── STACK ───────────────────────────────────────────────────────── LLM : Ollama llama3.2, temperature=0.3 (via langchain-ollama) Framework : LangGraph create_react_agent (prebuilt ReAct loop) Search : DuckDuckGo via duckduckgo-search Python package (free, no API key, no rate-limit registration) # ── TOOL (1) ────────────────────────────────────────────────────── web_search(query: str) → str - Use DDGS().text(query, max_results=5) in a context manager - For each result: extract title, href (URL), body (snippet) - Return numbered list: [1] Title URL : https://... Info: snippet text [2] ... - On any exception: return friendly error, suggest rephrasing # ── BEHAVIOUR ───────────────────────────────────────────────────── The agent may call web_search multiple times per question to: - Search for different angles of the same scenario - Find historical context after getting current news - Verify claims from a first search result # ── ENTRY POINT ─────────────────────────────────────────────────── Interactive while-loop CLI chat (agent.py): - Print header with model, tool name, and 3 example queries: "What is the current political situation in France?" "Analyze the impact of US-China trade tensions." "What are the key issues in the upcoming UK elections?" - Exit on "quit" / "exit" / "q" / Ctrl+C # ── FILES ───────────────────────────────────────────────────────── tools.py ← web_search tool agent.py ← build_agent(), ask(), main() requirements.txt ← langchain, langchain-ollama, langchain-community, langgraph, duckduckgo-search .venv/
