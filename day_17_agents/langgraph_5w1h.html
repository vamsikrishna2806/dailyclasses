WWhat is LangGraph?

A way to draw your AI app as a map

LangGraph is a Python (and JavaScript) library for building AI agents as a graph: boxes connected by arrows. Each box does one job, each arrow says where to go next, and a shared notebook carries information along the way. The arrows can branch and loop back, which lets an agent retry or keep working until the job is done.

📒
State

The shared notebook. Every step can read it and write to it.

Like your bag on a train trip: it travels with you.

🧑‍🍳
Nodes

The workers. Each one is a plain Python function: call an LLM, search, run a tool.

Like stations where something happens.

➡️
Edges

The arrows. A normal edge always goes to the same place. A conditional edge picks the next stop based on the state.

Like train tracks, plus a junction signal.

The metro-map picture 🚇

Station = Node Track = Edge Junction = Conditional edge Train carrying the notebook = State
One-liner: LangGraph = State (notebook) + Nodes (workers) + Edges (arrows, which can loop). You draw the map, and LangGraph runs it.
WWhy do we need it?

Chains only go forward. Real work needs loops.

With plain LangChain you build a chain: step A, then B, then C, always in a straight line. That's fine for simple tasks. But an agent often has to try something, check the result, and go back if it failed. A straight line can't go back. A graph can.

HHow does it work?

Build a graph in 5 steps, then watch it run

Example: a poem writer with a reviewer. One node writes a poem, another reviews it. If the review isn't "GOOD", we loop back and rewrite (at most 3 tries).

1StateDefine the notebook with a TypedDict
2NodesWrite functions that return updates
3Edgesadd_edge and add_conditional_edges
4Compileg.compile() checks and builds it
5Invokeapp.invoke({...}) runs it

💾 Checkpointer = memory

Pass checkpointer=MemorySaver() to compile() and the graph saves state after every step. Chats remember earlier turns and runs can resume after a crash.

🙋 Human-in-the-loop

Call interrupt() inside a node to pause the graph, show something to a person, and continue once they approve.

🔧 Prebuilt agents

LangChain's create_agent gives you a ready-made "LLM ↔ tools" loop built on LangGraph, so you don't have to wire it by hand.

🧾 Recap

LangGraph on one screen

❓ What

A library to build AI agents as graphs of State, Nodes and Edges.

💡 Why

Chains can't loop. Agents need retries, branches, memory and human approval.

👥 Who

Made by LangChain Inc. Used by AI engineers. Learn it once you know Python and LangChain basics.

⏰ When

Released Jan 2024, 1.0 in Oct 2025. Use it when your app loops, branches or uses tools.

📍 Where

The orchestration layer above LangChain. Runs on a laptop, a server or the cloud.

🛠️ How

State → Nodes → Edges → compile() → invoke().

🎯 LangChain gives you the pieces. LangGraph decides the path: which piece runs next, and whether to loop back.
