# Debate Agent — Plain English Guide

## What does this agent do?

This agent is like a **school debate club**. Two students are told which side to defend, they take turns answering each other, and a teacher (the judge) listens to everything and picks the winner.

## How to talk to it

Type a statement people can disagree about:

- "Homework should be banned"
- "Cats are better than dogs"
- "School should start later"

## How it works (simple version)

1. You give a motion
2. **PRO** speaks first and argues for it
3. **CON** answers PRO's point and argues against
4. They repeat for a fixed number of rounds
5. The **judge** reads the whole debate and names a winner with a reason

## The team

- **PRO** — always argues for the motion
- **CON** — always argues against it
- **Judge** — neutral — reads everything and decides

## Example conversation

```
You:    Homework should be banned

🟢 PRO: Homework steals time from sleep, family and hobbies ...
🔴 CON: My opponent forgets that practice builds skills ...
🟢 PRO: Practice can happen in class, where teachers can help ...
🔴 CON: ...

⚖️  Verdict:
Winner: PRO
Reason: PRO answered every point and offered a practical alternative.
```

## Why is this useful?

Debate-style loops help catch weak arguments, check plans from both sides, and give a user a balanced view instead of a one-sided answer.
