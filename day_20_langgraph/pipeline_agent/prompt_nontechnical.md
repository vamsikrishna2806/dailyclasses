# Pipeline Agent — Plain English Guide

## What does this agent do?

This agent is like a **small factory assembly line** for blog posts. Nobody is in charge — each worker simply does their one job and passes the work to the next person in line.

## How to talk to it

Type just a topic:

- "Why sleep matters"
- "Learning to cook"
- "How volcanoes work"

## How it works (simple version)

1. You give a topic
2. The **outliner** plans three points
3. The **writer** turns the plan into a short post
4. The **editor** polishes the post
5. The **headline writer** invents a catchy title
6. The **quality gate** counts the words and reading time
7. You receive the finished post

## The team

- **Outliner** — plans the structure
- **Writer** — writes the first draft
- **Editor** — fixes grammar and clarity
- **Headline writer** — picks the title
- **Quality gate** — not an AI — plain code that counts words

## Example conversation

```
You:    Why sleep matters

[outliner] planning the structure...
[writer]   writing the first draft...
[editor]   polishing the draft...
[headline] choosing a headline...
[quality]  measuring the result

# Sleeping Well: The Key to a Healthier, Happier You
Sleep is essential for physical and mental restoration ...
(106 words · reading time 32 sec)
```

## Why is this useful?

Whenever work always flows the same way (draft → review → publish, extract → clean → summarise), a pipeline is the right choice. It is easy to understand, test and extend.
